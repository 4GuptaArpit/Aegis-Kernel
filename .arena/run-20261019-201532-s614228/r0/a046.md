# Aegis-Kernel UI/UX Architecture & Supercomputer Design System

## Executive Architecture Summary
Aegis-Kernel is an autonomous GPU invariant and kernel proving workbench engineered for the **Nebius × NVIDIA Global AI Hackathon '26**. The system orchestrates a closed-loop adversarial tournament between the Nemotron Red Adversary fuzzer and Nemotron Blue Triton healer across NVIDIA Hopper H100 and Blackwell B200 hardware.

To solve the visual congestion, spatial clutter, and generic aesthetic flaws of previous revisions, this specification delivers a **Bimodal Cyber-Physical Supercomputer Interface**. It marries strict ergonomic breathing room with hardware-authentic GPU telemetry, holographic particle/reactor aesthetics, and real-time parameter scrubbing.

---

## 1. Ergonomic Spatial Architecture & Bimodal Layout System

The interface rejects vertical card stacking and congested multi-column dashboard patterns. Instead, it introduces an adaptive, stateful dual-mode spatial layout:

```
+-------------------------------------------------------------------------------------------------------+
|  [SHIELD] AEGIS // KERNEL  |  HW TARGET: [H100 SXM5 v]  |  WORKLOAD: [SwiGLU]  |  SCRUBBER: [1023 tok]  |
|  PIPELINE:  [01 Recon] ====> [02 Red Fuzz] ====> [03 Crash] ====> [04 Blue Heal] ====> [05 Verify]    |
+-------------------------------------------------------------------------------------------------------+
|  MODE TOGGLE: [ 01 Collider Deck | 02 Silicon Die & Warp | 03 AST & PTX | 04 Nsight & Waterfall ]     |
|               [ VIEW MODE: Focused Instrument (Default)  |  Executive Battle-Room (Bento) ]          |
+-------------------------------------------------------------------------------------------------------+
|                                                                                                       |
|                                       SPACIOUS PROVING VIEWPORT                                       |
|                  (Strict 2-Column Split Plane / Zero Clutter / High Aesthetic Energy)                 |
|                                                                                                       |
+-------------------------------------------------------------------------------------------------------+
|  DOCKABLE TELEMETRY HUD & LIVE CONSOLE TRAY [ TTY: nebius-h100-node-04 | 100KHz SM Sampling | ^ DOCK ] |
+-------------------------------------------------------------------------------------------------------+
```

### 1.1 The Two Master Viewport Modes
1. **Focused Instrument View (Deep Dive Navigation)**:
   - Divides the workbench into 4 isolated, highly focused, balanced 2-instrument viewports.
   - Eliminates overcrowding by never rendering more than 2 high-density cards simultaneously.
   - Retains a persistent stage status badge and execution runner.
2. **Executive Battle-Room Overview (Cinematic Bento)**:
   - Designed specifically for executive and hackathon judges.
   - Arranges the 4 core pillars (Collider Core, 132-SM Die Matrix, AST/PTX Diff, and Nsight Speedup Waterfall) into a unified, non-scrolling, high-density HUD grid with responsive scaling.

### 1.2 The 4 Focused Instrument Stages
- **Stage 01: Autonomous Red vs Blue Collider & Invariant Attestation**
  - **Left Wing**: Nemotron 3 Ultra Red Fuzzer synthesizing pathological ragged-token tensors (`seq_len = 1023`, `tail_threads = 31`).
  - **Center Reactor**: Glowing particle collision core representing the Nebius ephemeral hardware sandbox.
  - **Right Wing**: Nemotron 70B Blue Healer generating Triton `@p0` hardware predication masks.
  - **Lower Unit**: Cryptographic Attestation Block (`0x7f56b9fe02089399`) verifying formal invariant safety.
- **Stage 02: 132-SM Hopper GH100 Die & 32-Lane Warp Predication Matrix**
  - **Left Wing**: Interactive TSMC 4N physical die topology with 132 Streaming Multiprocessors across 8 GPCs, showing active MMU page fault traps on SM 14 during attack, and uniform green resonance upon verification.
  - **Right Wing**: 32-lane SIMT Warp 0 visualizer detailing exact 32-bit register allocations, thread lane statuses (`T0`–`T31`), memory addresses, and zero-overhead hardware predication registers (`@p0 = 1` vs `@p0 = 0`).
- **Stage 03: Dual AST Syntax Diff & Hopper PTX Disassembly Studio**
  - **Left Pane**: Monaco-styled vulnerable CUDA C++ kernel highlighting unbounded pointer arithmetic and SIGSEGV memory faults.
  - **Right Pane**: Hardened Triton Python kernel with `tl.load(..., mask=mask, other=0.0)`.
  - **Sub-Inspector**: Disassembled Hopper PTX ISA v8.4 comparing raw unpredicated `ld.global.v2.f16` with hardened `@p0 ld.global.nc.v2.f16`.
- **Stage 04: Nsight Deep Telemetry HUD & 4-Tier Silicon Waterfall**
  - **Top Unit**: Real-time Nsight Compute 100KHz telemetry ribbon (Tensor Core FLOP saturation, 3.35 TB/s HBM3e bus utilization, and warp divergence metrics).
  - **Bottom Unit**: 4-Tier Silicon Memory Waterfall tracing dataflow through Global VRAM (HBM3e) -> 50MB L2 Cache Crossbar -> 228KB SM Shared Memory/TMA -> Tensor Core Register File.

### 3.1 `frontend/src/App.jsx`
Replace the monolith stage navigation in `frontend/src/App.jsx` with the bimodal spatial engine, integrating dockable console telemetry, live hardware parameter updates, and clean separation of concerns:

```jsx
import React, { useState } from 'react';
import ExecutiveCommandBar from './components/ExecutiveCommandBar';
import RedBlueArena from './components/RedBlueArena';
import HopperDieTopology from './components/HopperDieTopology';
import WarpVisualizer from './components/WarpVisualizer';
import CodeDiffInspector from './components/CodeDiffInspector';
import TerminalWindow from './components/TerminalWindow';
import NsightTelemetryHud from './components/NsightTelemetryHud';
import SiliconMemoryWaterfall from './components/SiliconMemoryWaterfall';
import MicDropDelta from './components/MicDropDelta';
import VerificationImpact from './components/VerificationImpact';
import Footer from './components/Footer';
import AttestationModal from './components/AttestationModal';
import { sound } from './utils/audio';
import { 
  ShieldCheck, 
  Layers, 
  Code2, 
  Activity, 
  Terminal, 
  LayoutGrid, 
  Maximize2, 
  Sliders, 
  ChevronUp, 
  ChevronDown 
} from 'lucide-react';

export default function App() {
  const [selectedHardware, setSelectedHardware] = useState('NVIDIA Hopper H100 SXM5');
  const [selectedFixture, setSelectedFixture] = useState('swiglu');
  const [selectedSm, setSelectedSm] = useState(14);
  const [seqLen, setSeqLen] = useState(1023);
  const [isRunning, setIsRunning] = useState(false);
  const [currentStage, setCurrentStage] = useState('IDLE');
  const [progress, setProgress] = useState(0);

  const [logs, setLogs] = useState([]);
  const [tavilyData, setTavilyData] = useState(null);
  const [redData, setRedData] = useState(null);
  const [blueData, setBlueData] = useState(null);
  const [metrics, setMetrics] = useState(null);
  const [attestation, setAttestation] = useState('0x7f56b9fe02089399');
  const [isModalOpen, setIsModalOpen] = useState(false);
  
  // Navigation & Viewport Modes
  const [activeWorkbenchTab, setActiveWorkbenchTab] = useState('collider'); // 'collider', 'silicon', 'code', 'telemetry'
  const [viewMode, setViewMode] = useState('focused'); // 'focused' or 'bento'
  const [isConsoleDrawerOpen, setIsConsoleDrawerOpen] = useState(false);

  const addLog = (text, type = 'info') => {
    const timestamp = new Date().toLocaleTimeString();
    setLogs(prev => [...prev, { text: `[${timestamp}] ${text}`, type }]);
  };

  const handleClearLogs = () => {
    sound.playClick();
    setLogs([]);
  };

  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);
    setTavilyData(null);
    setRedData(null);
    setBlueData(null);
    setMetrics(null);

    addLog(`[INIT] Engaging Aegis-Kernel Autonomous Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'TAVILY_RECON') {
          setCurrentStage('TAVILY');
          addLog(data.message, 'info');
        } else if (data.stage === 'TAVILY_RECON_COMPLETE') {
          setTavilyData(data.tavily_intel);
          addLog(`[TAVILY ORACLE] Verified 128-bit vector alignment & PTX ISA specs for Hopper SM_90a.`, 'success');
        } else if (data.stage === 'RED_ATTACK_SYNTHESIS') {
          setCurrentStage('RED_ATTACK');
          addLog(data.message, 'info');
        } else if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          setRedData(data.red_attack);
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
          addLog(data.red_attack.stack_trace, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(data.message, 'info');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setBlueData(data.blue_patch);
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'DUAL_VERIFY') {
          setCurrentStage('VERIFYING');
          addLog(data.message, 'info');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(data.message, 'success');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      {/* Executive Command Cockpit */}
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={(val) => {
          setSeqLen(val);
          addLog(`[SLIDER] Dynamic sequence length set to ${val} tokens`, 'info');
        }}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <main className="aegis-workbench-container">
        {/* Spatial Workbench Mode & Stage Navigation */}
        <div className="workbench-stage-nav-bar font-mono">
          <div className="stage-nav-tabs">
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'collider' && viewMode === 'focused' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('collider'); setViewMode('focused'); }}
            >
              <span className="nav-tag-num">01</span>
              <span>Red vs Blue Collider Deck</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'silicon' && viewMode === 'focused' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('silicon'); setViewMode('focused'); }}
            >
              <span className="nav-tag-num">02</span>
              <span>132-SM Die & 32-Warp Matrix</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'code' && viewMode === 'focused' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('code'); setViewMode('focused'); }}
            >
              <span className="nav-tag-num">03</span>
              <span>AST Diff & PTX Disassembly</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'telemetry' && viewMode === 'focused' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('telemetry'); setViewMode('focused'); }}
            >
              <span className="nav-tag-num">04</span>
              <span>Nsight Profiler & Memory Waterfall</span>
            </button>
          </div>

          <div className="stage-nav-controls">
            {/* Viewport Mode Switcher */}
            <div className="viewmode-toggle-cluster">
              <button 
                className={`viewmode-btn ${viewMode === 'focused' ? 'active' : ''}`}
                onClick={() => { sound.playClick(); setViewMode('focused'); }}
                title="Focused Stage Instrument"
              >
                <Maximize2 size={13} className="mr-1 inline" />
                Focused
              </button>
              <button 
                className={`viewmode-btn ${viewMode === 'bento' ? 'active' : ''}`}
                onClick={() => { sound.playClick(); setViewMode('bento'); }}
                title="Executive Overview Bento"
              >
                <LayoutGrid size={13} className="mr-1 inline" />
                Battle-Room
              </button>
            </div>

            {/* Live Telemetry Badge */}
            <div className="stage-nav-telemetry">
              <span className="nav-telemetry-badge">
                <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
                {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
              </span>
            </div>
          </div>
        </div>

        {/* Dynamic Spacious Viewport */}
        {viewMode === 'focused' ? (
          <div className="workbench-spacious-view">
            {/* STAGE 1: RED VS BLUE COLLIDER & DELTA */}
            {activeWorkbenchTab === 'collider' && (
              <div className="tab-view-container tab-view-fade">
                <RedBlueArena 
                  currentStage={currentStage}
                  isRunning={isRunning}
                  selectedFixture={selectedFixture}
                  metrics={metrics}
                  redData={redData}
                  blueData={blueData}
                />
                <div className="spacious-two-col-grid">
                  <MicDropDelta 
                    metrics={metrics} 
                    selectedFixture={selectedFixture} 
                  />
                  <VerificationImpact 
                    metrics={metrics} 
                    selectedFixture={selectedFixture}
                    onOpenPrModal={() => setIsModalOpen(true)}
                    onOpenJudgesOverview={() => setIsModalOpen(true)}
                  />
                </div>
              </div>
            )}

            {/* STAGE 2: SILICON DIE & 32-WARP EXECUTION MATRIX */}
            {activeWorkbenchTab === 'silicon' && (
              <div className="tab-view-container tab-view-fade">
                <div className="spacious-two-col-grid">

      )}

  );
}
```

## 4. Hardware Verification & Parameter Walkthrough

1. **Hardware Target Switcher**:
   - Selecting `NVIDIA Hopper H100 SXM5` instantiates 132 SMs, 8 GPCs, 3.35 TB/s HBM3e bandwidth, and SM_90a PTX ISA.
   - Selecting `NVIDIA Blackwell B200` re-scales telemetry to 160 SMs, 8.0 TB/s memory bus, and SM_100 architectural profiles.
2. **Dynamic Sequence Length Scrubber**:
   - Users can drag the sequence length slider from 64 to 8192 tokens.
   - Any value where `seqLen % 32 !== 0` immediately triggers the **RAGGED TAIL WARP** warning badge and displays the exact misaligned thread lane count in the HUD.
3. **Execution Proving Loop (Real-Time SSE)**:
   - Clicking **RUN PROVING GROUND** triggers a live Server-Sent Events stream from `http://localhost:8000/api/v1/execute/{fixture}`.
   - As the loop progresses through `TAVILY_RECON` -> `RED_ATTACK` -> `SANDBOX_FAIL` -> `BLUE_SYNTHESIS` -> `COMPLETE`, both the **Focused Instrument View** and **Executive Battle-Room** update in synchronized lockstep.
