# Aegis-Kernel UI-UX Architecture & Design System Specification
**Autonomous GPU Invariant & Kernel Proving Workbench (Nebius x NVIDIA Global AI Hackathon '26)**

---

## 1. Executive Summary & Strategic Trade-Off Decisions

The Aegis-Kernel workbench is designed to prove and harden autonomous Triton kernels against adversarial LLM attacks (Nemotron Red Fuzzer vs. Nemotron Blue Healer) on NVIDIA Hopper GH100 (132 SMs, 528 Tensor Cores) and Blackwell B200 architectures. 

Building an interface that commands absolute credibility with NVIDIA and Nebius system architects requires balancing two opposing forces: **dense hardware observability** (Nsight 100 kHz counters, 132 SM heatmaps, 32 SIMT warp vector predicates) and **cognitive breathing room** (spatial clarity, zero visual crowding, high-impact hierarchy).

### Strategic Architecture Options Matrix

| Evaluation Dimension | Option A: Monolithic HUD Dashboard (Dense Single-Page) | Option B: Linear Step-by-Step Wizard | Option C: Decoupled 4-Stage Spatial Stage Navigator + Omnipresent Cockpit (Selected) |
| :--- | :---: | :---: | :---: |
| **Aesthetic "GA-GA" Factor** | High initial flash, quickly devolves into sensory fatigue | Low, feels like a consumer onboarding tutorial | **Elite Cyber-Physical Supercomputer HUD** |
| **Breathing Room & Anti-Congestion** | ❌ Fails: Constant fight for vertical/horizontal pixels | Moderate: Single card focus, but hides critical telemetry | **Optimal: Dedicated viewports with strict 2–3 instrument bounds** |
| **Hardware Authenticity** | High, but unreadable due to overlapping metric widgets | Low, fragments concurrent GPU pipeline state | **Authentic: Full die topography, 32-lane warp vector matrix, PTX AST diff, 4-tier waterfall** |
| **Interactive Proving Ground Usability** | Controls buried or pushed below the fold | Disconnected from live telemetry | **Direct: Omnipresent Executive Cockpit with live scrubbing & dual-engine triggers** |
| **Production Polish & Reliability** | Risk of heavy layout re-renders & frame drops | High, but uninspiring | **Flawless 60 FPS CSS hardware-accelerated transforms & zero compile warnings** |

### Explicit Design Trade-Offs

1. **Selective Viewport Isolation over Unified Monolith**:
   - *Choice*: Partition the workbench into 4 synchronized spatial stages (`01 Collider & Speedup Delta`, `02 Silicon Die & Warp Matrix`, `03 PTX ISA Disassembly & AST Diff`, `04 Nsight Telemetry & Memory Waterfall`).
   - *What We Give Up*: The ability to see all 10 GPU instruments on a single screen without switching tabs.
   - *Why It Wins*: Prevents the visual claustrophobia of typical hackathon submissions. Gives each technical instrument (like the 132-SM die) generous physical dimensions (min 420px height) to display genuine architectural detail.
2. **Deterministic Hardware State over Generic Dynamic Graphs**:
   - *Choice*: Deep, authentic modeling of GH100 hardware invariants (SM 14 warp-divergent trap, `@p0` vector mask predicates, 228 KB shared SRAM bank conflicts, 3.35 TB/s HBM3e bandwidth).
   - *What We Give Up*: Generic, interchangeable chart libraries.
   - *Why It Wins*: NVIDIA and Nebius evaluators immediately spot generic mockups. Authentic PTX instructions (`ld.global.nc.v4.f32`) and Nsight telemetry flags establish undeniable technical depth.
3. **Controlled Cyber-Physical Neon Hierarchy**:
   - *Choice*: Deep obsidian background (`#03060D`) paired with NVIDIA Emerald (`#00FF88`), Plasma Coral (`#FF0055`), and Cyber Cyan (`#00F0FF`).
   - *What We Give Up*: Traditional corporate light/dark neutral modes.
   - *Why It Wins*: Creates high-contrast, luminescent focus on active warps and memory bottlenecks while maintaining strict WCAG AA contrast against pitch-black backgrounds.

## 2. Core Architectural System: Spatial Workbench Navigation

To eliminate congestion while keeping execution control immediate, the interface is split into two primary layers:
1. **The Omnipresent Executive Command Cockpit** (Pinned Header): Holds the hardware target selector (`Hopper H100 SXM5` vs. `Blackwell B200`), workload fixture switcher (`swiglu`, `flash_attn_v3`, `moe_gather`), dynamic sequence length scrubber (`128` to `8192` tokens), and the one-click **"Engage Proving Collider"** ignition button.
2. **The 4-Stage Spatial Stage Navigator**: A persistent, low-profile tab bar with active telemetry badges and audio-tactile feedback.
