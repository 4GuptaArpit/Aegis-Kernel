## 1. Executive Summary & Contrarian Architecture

### The Default Design Fallacy
The standard approach to AI hackathon workbenches falls into two traps:
1. **The Monolithic SaaS Dashboard**: Stacking cards, charts, code blocks, and logs vertically into an unreadable, claustrophobic 600px scroll pit where components constantly fight for ocular attention.
2. **The Naive Tabbed Silo (Baseline Pitfall)**: Fragmenting the system into disconnected tabs where the user loses the holistic cause-and-effect loop. When an engineer adjusts a dynamic sequence length slider on Tab 1, they cannot witness the hardware memory waterfall crash on Tab 4 or the SM MMU page fault on Tab 2.

### The Contrarian Solution: Orthogonal Viewport & Spatial Telemetry Cockpit
Aegis-Kernel resolves this tension through an **Orthogonal Viewport Architecture**:
- **Persistent Executive Cockpit**: Houses the global hardware target switcher, workload presets, dynamic sequence length scrubber, and a 5-stage synchronous proving stepper that remains omnipresent across all modalities.
- **4 Spatial Proving Lenses + Unified Super-Collider Mode**:
  - `Stage 01: Red vs Blue Collider & Mic-Drop Delta` (High-level algorithmic warfare, performance delta, attestation proof).
  - `Stage 02: 132-SM Silicon Die & 32-Warp Matrix` (Hardware execution topology, MMU page faults, warp predication).
  - `Stage 03: AST Diff & PTX Disassembly` (Source-level CUDA/Triton diff alongside Hopper SM_90a PTX ISA assembly).
  - `Stage 04: Nsight Profiler & 4-Tier Memory Waterfall` (100KHz telemetry, HBM3e $\to$ L2 $\to$ SRAM $\to$ Tensor Core roofline dataflow).
  - **Executive Super-Collider Overview**: A high-density, breathing-room master view that synoptically visualizes all 4 subsystems simultaneously on ultra-wide / 1440p displays without cramping.

### 3.1 132-SM Physical Die Topology
- **132 Streaming Multiprocessors**: Grouped logically across 8 Graphics Processing Clusters (GPCs).
- **Physical Defect Mapping**: Identifies SM 14 as the core tripping an MMU page fault during ragged sequence fuzzing.
- **Real-Time Crossbar Activity**: Live visual traffic indicators showing 50MB L2 cache bus utilization.

### 3.2 SIMT 32-Thread Warp Matrix
- **32 Physical Thread Lanes ($T_0$ to $T_{31}$)**: Visualizes a single warp executing lockstep instructions.
- **Hardware Predication (`@p0`)**:
  - In vulnerable CUDA: Thread lanes exceeding boundary limit trigger memory corruption (SIGSEGV 139).
  - In Aegis Hardened Triton: Boundary threads have `@p0 = 0`, squashing execution in hardware with zero branch divergence penalty.
- **Hex Memory Address Inspector**: Shows exact 64-bit aligned pointers (e.g., `0x7F4E8244`).

### 3.3 PTX ISA Disassembly & Source Code Diff
- Side-by-side AST comparison between unmasked CUDA C++ and hardened Triton Python.
- Real Hopper PTX assembly comparing raw unpredicated loads (`ld.global.v2.f16`) against hardware-predicated loads (`@p0 ld.global.nc.v2.f16`).

### 3.4 4-Tier Memory Waterfall & Nsight HUD
- **Tier 1 (HBM3e)**: Compares 3x PyTorch unfused roundtrips against 1x streamed Triton kernel.
- **Tier 2 (L2 Crossbar)**: 94.2% hit rate with 128-bit tile coalescing.
- **Tier 3 (SRAM / TMA)**: 184 KB shared memory allocation with zero bank conflicts.
- **Tier 4 (Tensor Cores)**: Roofline saturation yielding 418.5 TFLOPS sustained compute.

## 4. Complete Code Implementation

### 4.1 Enhanced `frontend/src/App.jsx`
The implementation below introduces:
1. **Fluid Workbench Tab Navigation** with live stage indicators.
2. **Executive Overview / Super-Collider Mode** toggle allowing simultaneous high-density inspection without cramping.
3. **Responsive Grid Layout** maintaining spacious margins and breathing room across all viewports.

```jsx
import React, { useState } from 'react';
import ExecutiveCommandBar from './components/ExecutiveCommandBar';
import RedBlueArena from './components/RedBlueArena';
import HopperDieTopology from './components/HopperDieTopology';
import WarpVisualizer from './components/WarpVisualizer';
import CodeDiffInspector from './components/CodeDiffInspector';
import TerminalWindow from './components/TerminalWindow';
import NsightTelemetryHud from './components/NsightTelemetryHud';
import SiliconMemoryWaterfall from './components/SiliconMemoryWaterfall';
import MicDropDelta from './components/MicDropDelta';
import VerificationImpact from './components/VerificationImpact';
import Footer from './components/Footer';
import AttestationModal from './components/AttestationModal';
import { sound } from './utils/audio';
import { LayoutGrid, Layers, Cpu, Code2, Activity } from 'lucide-react';

export default function App() {
  const [selectedHardware, setSelectedHardware] = useState('NVIDIA Hopper H100 SXM5');
  const [selectedFixture, setSelectedFixture] = useState('swiglu');
  const [selectedSm, setSelectedSm] = useState(14);
  const [seqLen, setSeqLen] = useState(1023);
  const [isRunning, setIsRunning] = useState(false);
  const [currentStage, setCurrentStage] = useState('IDLE');
  const [progress, setProgress] = useState(0);

  const [logs, setLogs] = useState([]);
  const [tavilyData, setTavilyData] = useState(null);
  const [redData, setRedData] = useState(null);
  const [blueData, setBlueData] = useState(null);
  const [metrics, setMetrics] = useState(null);
  const [attestation, setAttestation] = useState('0x7f56b9fe02089399');
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [activeWorkbenchTab, setActiveWorkbenchTab] = useState('collider'); // 'collider', 'silicon', 'code', 'telemetry', 'super'

  const addLog = (text, type = 'info') => {
    const timestamp = new Date().toLocaleTimeString();
    setLogs(prev => [...prev, { text: `[${timestamp}] ${text}`, type }]);
  };

  const handleClearLogs = () => {
    sound.playClick();
    setLogs([]);
  };

  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);
    setTavilyData(null);
    setRedData(null);
    setBlueData(null);
    setMetrics(null);

    addLog(`[INIT] Engaging Aegis-Kernel Autonomous Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'TAVILY_RECON') {
          setCurrentStage('TAVILY');
          addLog(data.message, 'info');
        } else if (data.stage === 'TAVILY_RECON_COMPLETE') {
          setTavilyData(data.tavily_intel);
          addLog(`[TAVILY ORACLE] Verified 128-bit vector alignment & PTX ISA specs for Hopper SM_90a.`, 'success');
        } else if (data.stage === 'RED_ATTACK_SYNTHESIS') {
          setCurrentStage('RED_ATTACK');
          addLog(data.message, 'info');
        } else if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          setRedData(data.red_attack);
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
          addLog(data.red_attack.stack_trace, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(data.message, 'info');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setBlueData(data.blue_patch);
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'DUAL_VERIFY') {
          setCurrentStage('VERIFYING');
          addLog(data.message, 'info');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(data.message, 'success');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      {/* Executive Command Cockpit */}
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={(val) => {
          setSeqLen(val);
          addLog(`[SLIDER] Dynamic sequence length set to ${val} tokens`, 'info');
        }}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <div className="aegis-workbench-container">
        {/* Spatial Workbench Stage Navigation Bar */}
        <div className="workbench-stage-nav-bar font-mono">
          <div className="stage-nav-tabs">
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'collider' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('collider'); }}
            >
              <span className="nav-tag-num">01</span>
              <span>Red vs Blue Collider & Delta</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'silicon' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('silicon'); }}
            >
              <span className="nav-tag-num">02</span>
              <span>132-SM Die & 32-Warp Matrix</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'code' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('code'); }}
            >
              <span className="nav-tag-num">03</span>
              <span>AST Diff & PTX Disassembly</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'telemetry' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('telemetry'); }}
            >
              <span className="nav-tag-num">04</span>
              <span>Nsight Profiler & Memory Waterfall</span>
            </button>
            <button 
              className={`stage-nav-btn btn-super-mode ${activeWorkbenchTab === 'super' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('super'); }}
              title="Activate Synoptic Multi-Instrument Super-Collider View"
            >
              <LayoutGrid size={13} className="inline mr-1 text-nvidia" />
              <span>Super-Collider Lens</span>
            </button>
          </div>

          <div className="stage-nav-telemetry">
            <span className="nav-telemetry-badge">
              <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
              {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
            </span>
          </div>
        </div>

        {/* Dynamic Spatial Workbench Content View */}
        <div className="workbench-spacious-view">
          {/* TAB 1: RED VS BLUE COLLIDER & MIC-DROP DELTA */}
          {activeWorkbenchTab === 'collider' && (
            <div className="tab-view-container tab-view-fade">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
                redData={redData}
                blueData={blueData}
              />

              <div className="spacious-two-col">
                <MicDropDelta 
                  metrics={metrics} 
                  selectedFixture={selectedFixture} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>

              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {/* TAB 2: SILICON DIE & 32-WARP EXECUTION MATRIX */}
          {activeWorkbenchTab === 'silicon' && (
            <div className="tab-view-container tab-view-fade">
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                />
              </div>

              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
            </div>
          )}

          {/* TAB 3: CODE DIFF & PTX DISASSEMBLY */}
          {activeWorkbenchTab === 'code' && (
            <div className="tab-view-container tab-view-fade">
              <CodeDiffInspector 
                selectedFixture={selectedFixture} 
                blueData={blueData} 
              />
              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {/* TAB 4: NSIGHT TELEMETRY & SILICON MEMORY WATERFALL */}
          {activeWorkbenchTab === 'telemetry' && (
            <div className="tab-view-container tab-view-fade">
              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall 
                  metrics={metrics} 
                  selectedHardware={selectedHardware} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
            </div>
          )}

          {/* TAB 5: SYNOPTIC SUPER-COLLIDER MULTI-INSTRUMENT LENS */}
          {activeWorkbenchTab === 'super' && (
            <div className="tab-view-container tab-view-fade super-collider-view">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
                redData={redData}
                blueData={blueData}
              />
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                />
              </div>
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall 
                  metrics={metrics} 
                  selectedHardware={selectedHardware} 
                />
                <CodeDiffInspector 
                  selectedFixture={selectedFixture} 
                  blueData={blueData} 
                />
              </div>
              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}
        </div>
      </div>

      {/* Global Footer */}
      <Footer />

      {/* Attestation & PR Modal */}
      <AttestationModal 
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        fixtureId={selectedFixture}
        hardwareTarget={selectedHardware}
        attestationHash={attestation}
      />
    </div>
  );
}
```
