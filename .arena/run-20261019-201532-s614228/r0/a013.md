# Aegis-Kernel UI/UX Architecture & Production Design System
*Autonomous GPU Invariant & Kernel Proving Workbench (NVIDIA Hopper GH100 & Blackwell GB200)*

---

## 1. Executive Summary & Design Vision

**Aegis-Kernel** is not a standard software dashboard; it is a cyber-physical proving ground where autonomous LLMs—**Nemotron Red Adversary** and **Nemotron Blue Healer**—collide in real-time on NVIDIA microarchitectures. 

To deliver an interface that commands attention from NVIDIA and Nebius systems architects, this design system breaks away from SaaS dashboard conventions. It replaces dull cards and generic dark modes with a **Cyber-Physical Quantum Supercomputer HUD**:
- **Obsidian Void Backdrop (`#03060D`)**: Deep, low-reflectance carbon silicon canvas.
- **Laser Emerald (`#00FF88`) & Plasma Coral (`#FF0055`)**: Functional energy indicators displaying non-predicated bus panics vs. hardened, verified hardware states.
- **Holographic Circuit Traces & Dynamic Scanlines**: Spatial depth and tactile reactivity that simulate actual die-level telemetry.
- **De-congested 4-Stage Spatial Workbench with Omni-Mode**: Eliminates visual crowding by giving high-density GPU instruments dedicated operational focus while retaining continuous global cockpit telemetry.

## 2. Inversion Analysis: Systematic Failure Prevention

To guarantee long-term viability and tournament victory, we apply an **Inversion Framework**—identifying every failure pattern of typical GPU tooling and designing structural guarantees against them.

| Failure Mode | Root Cause in Conventional UIs | Aegis-Kernel Architectural Counter-Measure | 6-Month Longevity Guarantee |
| :--- | :--- | :--- | :--- |
| **1. Visual Congestion & Cognitive Overload** | Cramming all 8 dense instruments (132 SMs, 32 warps, diffs, profiler, logs) onto a single screen. | **Spatial Stage Architecture**: 4 focused stages with clean spatial separation + an **Omni-Overview Mode** toggle. | New instruments can be added as stages without altering the footprint of existing views. |
| **2. "Theme Swap" Superficiality** | Simple white-to-black palette inversion without hardware aesthetic depth. | **Quantum Silicon Design System**: Authentic glowing shaders, circuit grid geometry, pulsed laser busses, and glowing typography. | Centralized CSS tokens and Tailwind theme aliases prevent ad-hoc hardcoded values. |
| **3. Hardware Inauthenticity** | Fake or generic AI metrics with no correlation to real GPU hardware. | **Hopper GH100 & Blackwell GB200 Telemetry**: Authentic 132 SM die topology, SIMT 32-lane warp matrices, `@p0` hardware predication, and 4-tier memory hierarchies. | Clean hardware abstraction layer allows adding future architectures (e.g., Blackwell Ultra, Rubin) via declarative specs. |
| **4. Static / Non-Interactive Dead Ends** | Static charts that do not react to parameter manipulation. | **Dynamic Silicon Scrubber**: Interactive sequence length slider dynamically calculating ragged warp tails, unaligned memory loads, and `@p0` predication masks in real time. | Parameter change events propagate via unified event streams, compatible with WebSocket / SSE backend replays. |
| **5. Brittle Maintenance & Component Drift** | Tightly coupled state and styles that break when developers add new metrics. | **Predictable Component Contracts**: Strict props interfaces, decoupled audio engine, centralized token registry, and zero compile warnings. | Strict typing, scoped CSS utility classes, and isolated visual components ensure drop-in maintainability. |

### 5.2 Dynamic Sequence Length Scrubber & SIMT Predication Engine
When users scrub the **Dynamic Sequence Length Slider** (128 to 2048 tokens), the UI instantly calculates SIMT boundary conditions:
- **Warp Alignment Check**: `seqLen % 32 === 0`
- **Tail Residual**: `tailLanes = seqLen % 32`
- **Visual Feedback**:
  - *Clean Boundary*: Emerald badge `"WARP ALIGNED (128-bit Coalesced)"`
  - *Ragged Boundary*: Pulsing Coral/Amber alert `"RAGGED BOUNDARY (Tail: X/32 Lanes Trapped)"`
  - *Warp Visualizer Reaction*: Thread lanes $0 \dots X-1$ illuminate as active loads; lanes $X \dots 31$ switch to `@p0 == 0` suppressed zero-registers in hardened mode, or trigger MMU bus panics in vulnerable mode.

```jsx
  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);
    setTavilyData(null);
    setRedData(null);
    setBlueData(null);
    setMetrics(null);

    addLog(`[INIT] Engaging Aegis-Kernel Autonomous Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'TAVILY_RECON') {
          setCurrentStage('TAVILY');
          addLog(data.message, 'info');
        } else if (data.stage === 'TAVILY_RECON_COMPLETE') {
          setTavilyData(data.tavily_intel);
          addLog(`[TAVILY ORACLE] Verified 128-bit vector alignment & PTX ISA specs for Hopper SM_90a.`, 'success');
        } else if (data.stage === 'RED_ATTACK_SYNTHESIS') {
          setCurrentStage('RED_ATTACK');
          addLog(data.message, 'info');
        } else if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          setRedData(data.red_attack);
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
          addLog(data.red_attack.stack_trace, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(data.message, 'info');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setBlueData(data.blue_patch);
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'DUAL_VERIFY') {
          setCurrentStage('VERIFYING');
          addLog(data.message, 'info');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(data.message, 'success');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={(val) => {
          setSeqLen(val);
          addLog(`[SLIDER] Dynamic sequence length set to ${val} tokens`, 'info');
        }}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <main className="aegis-workbench-container">
        {/* Spatial Stage Navigation Bar */}
        <nav className="workbench-stage-nav-bar font-mono" aria-label="Workbench Stage Navigation">
          <div className="stage-nav-tabs">
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'collider' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('collider'); }}
            >
              <span className="nav-tag-num">01</span>
              <span>Red vs Blue Collider & Delta</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'silicon' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('silicon'); }}
            >
              <span className="nav-tag-num">02</span>
              <span>132-SM Die & 32-Warp Matrix</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'code' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('code'); }}
            >
              <span className="nav-tag-num">03</span>
              <span>AST Diff & PTX Disassembly</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'telemetry' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('telemetry'); }}
            >
              <span className="nav-tag-num">04</span>
              <span>Nsight Profiler & Memory Waterfall</span>
            </button>
          </div>

          <div className="stage-nav-telemetry">
            <span className="nav-telemetry-badge">
              <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
              {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
            </span>
          </div>
        </nav>

        {/* Dynamic Spatial View Container */}
        <section className="workbench-spacious-view">
          {activeWorkbenchTab === 'collider' && (
            <div className="tab-view-container">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
                redData={redData}
                blueData={blueData}
              />
              <div className="spacious-two-col">
                <MicDropDelta 
                  metrics={metrics} 
                  selectedFixture={selectedFixture} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {activeWorkbenchTab === 'silicon' && (
            <div className="tab-view-container">
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                />
              </div>
              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
            </div>
          )}

          {activeWorkbenchTab === 'code' && (
            <div className="tab-view-container">
              <CodeDiffInspector 
                selectedFixture={selectedFixture} 
                blueData={blueData} 
              />
              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {activeWorkbenchTab === 'telemetry' && (
            <div className="tab-view-container">
              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall 
                  metrics={metrics} 
                  selectedHardware={selectedHardware} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
            </div>
          )}
        </section>
      </main>

      <Footer />

      <AttestationModal 
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        fixtureId={selectedFixture}
        hardwareTarget={selectedHardware}
        attestationHash={attestation}
      />
    </div>
  );
}
```

   ```javascript
   { id: 'NVIDIA Blackwell Ultra B300', label: 'Blackwell Ultra B300', spec: '288GB · SM_102 · 12.0 TB/s' }
   ```

   ```javascript
   const smMap = {
     'NVIDIA Hopper H100 SXM5': 132,
     'NVIDIA Blackwell B200': 160,
     'NVIDIA Blackwell Ultra B300': 192
   };
   const totalSms = smMap[selectedHardware] || 132;
   ```
