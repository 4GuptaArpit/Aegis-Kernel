# Aegis-Kernel UI-UX Architecture & Design System Specification
**Autonomous GPU Invariant & Kernel Proving Workbench**  
*Nebius × NVIDIA Global AI Hackathon '26*

---

## 1. Executive Summary & Design Philosophy

The **Aegis-Kernel Workbench** is engineered as a mission-critical, cyber-physical HPC command center for autonomous GPU kernel verification and synthesis. Unlike conventional SaaS dashboards that compress dense data into suffocating card grids or generic enterprise tables, Aegis-Kernel models the physical reality of modern high-performance computing silicon (NVIDIA Hopper GH100 and Blackwell B200 architectures).

### Core Pillars:
1. **The "GA-GA" Factor (Sovereign HPC Aesthetic)**:
   - Deep obsidian void (`#03060D`) accented by pure spectral emitters: NVIDIA Laser Emerald (`#00FF88`), Plasma Coral (`#FF0055`), and Superconductor Cyan (`#00F0FF`).
   - Micro-etched holographic PCB traces, scanlines, and 120Hz smooth particle/plasma reactor animations that communicate physical execution rather than static database state.
2. **Spatial Decoupling & Breathing Room**:
   - Zero card congestion. The interface eliminates 600px vertical scrolling monoliths and side-by-side overlaps by introducing a **4-Stage Spatial Workbench Navigation System**. Each stage delivers dedicated spatial balance, generous paddings (24px–32px), distinct optical focal points, and clear typographical hierarchy.
3. **Rigorous Hardware Authenticity**:
   - Direct physical mapping of the Hopper GH100 architecture: 132 Streaming Multiprocessors across 8 GPCs, SIMT 32-thread warps with live lane status, zero-overhead `@p0` hardware predication, 4-tier memory hierarchy (HBM3e -> L2 Cache -> SM Shared Memory / SRAM -> Tensor Cores), and real-time Nsight 100KHz telemetry counters.
4. **Interactive Proving Ground**:
   - Real-time sequence length scrubbers (triggering tail-effect ragged warp divergence), dynamic hardware target switching (Hopper H100 vs Ada L40S vs Blackwell B200), workload fault fixtures (SwiGLU, RMSNorm, Online Softmax), and dual-channel verification rings.

## 2. Inversion Analysis: Systematic Failure Preemption

To guarantee technical and aesthetic superiority over existing baselines, the architecture systematically identifies and neutralizes all potential failure modes:

| Failure Mode | Root Cause in Conventional Interfaces | Aegis-Kernel Architectural Countermeasure |
| :--- | :--- | :--- |
| **Visual Congestion** | Forcing all 8+ instruments onto one screen simultaneously. | **4-Stage Spatial Stage Navigator**; max 2–3 coordinated instruments per view with spacious responsive containers (`max-w-[1600px]`, `gap-6`, `p-6`). |
| **"Hackathon Card Slop"** | Standard rounded white/gray rectangles with drop shadows. | **Cyber-physical chassis design**: angled chamfers (`clip-path: polygon(...)`), semi-transparent luminous borders (`rgba(0, 255, 136, 0.18)`), laser accent bars, and reactive glows. |
| **Hardware Inaccuracy** | Showing random graphs or generic CPU/RAM percentages. | **Precise GH100 Silicon Die mapping**: 132 interactive SM nodes, 50MB crossbar L2 cache, 32 warp SIMT execution matrix with `@p0` predicate bits, and 3.35 TB/s HBM3e bandwidth waterfall. |
| **Static / Non-Interactive** | Mock data that does not react to user input. | **Dynamic Interactive Scrubber & SSE Stream**: adjusting sequence length dynamically recalculates thread masking (`seqLen % 32`), live SSE connects to backend runner. |
| **Sensory Disconnect** | Silent state transitions without auditory or physical feedback. | **Synthesized Web Audio Engine**: custom high-tech FM synthesis chirps, alerts, and proving hums for tactile user confirmation. |

## 3. Assumptions & Target Specifications

- **Target Architecture**: NVIDIA Hopper GH100 SXM5 (SM_90a, 132 SMs, 80GB HBM3e @ 3.35 TB/s, TSMC 4N) with extensible support for Blackwell B200 (SM_100, 192GB HBM3e @ 8.0 TB/s).
- **Target Workloads**:
  1. `swiglu`: Fused SwiGLU MLP (LLaMA-3 / Mistral) — OOB memory violation (SIGSEGV 139) on unaligned token sequences.
  2. `rmsnorm`: Vectorized RMSNorm (Qwen-2.5 / DeepSeek) — Silent Data Corruption (SDC) caused by unpredicated warp reduction tails.
  3. `softmax`: Online Fused Softmax (FlashAttention-v3) — Numerical NaN overflow during dynamic sequence scaling.
- **Technology Stack**: React 18, Tailwind CSS, Lucide Icons, Web Audio API, Server-Sent Events (SSE) telemetry transport.

## 4. UI-UX Spatial Workbench Architecture

The interface is structured into three coordinated visual zones:

```
+----------------------------------------------------------------------------------------------------+
| 1. EXECUTIVE COMMAND BAR (Cockpit Top-Strip)                                                       |
| Brand Lockup | Hardware Selector | Workload Switcher | Seq Scrubber | Invariant Attestation | Proving Trigger |
+----------------------------------------------------------------------------------------------------+
| 2. SPATIAL STAGE NAVIGATOR                                                                         |
| [01 Red vs Blue Collider]  [02 132-SM & Warp Matrix]  [03 AST & PTX Diff]  [04 Nsight & Waterfall] |
+----------------------------------------------------------------------------------------------------+
| 3. ACTIVE STAGE WORKBENCH CONTAINER (Spacious, breathing layout)                                   |
|                                                                                                    |
|  [ Stage-Specific Instrument A ]                  [ Stage-Specific Instrument B ]                  |
|                                                                                                    |
|  [ Full-Width Coordinated Telemetry / Terminal Console ]                                           |
+----------------------------------------------------------------------------------------------------+
| 4. GLOBAL SYSTEM TELEMETRY FOOTER                                                                  |
+----------------------------------------------------------------------------------------------------+
```

### Stage Breakdown & Information Hierarchy:

#### Stage 01: Red vs Blue Collider & Delta Engine
- **Primary Hero**: `RedBlueArena` — A particle-charged battleground displaying the Nemotron Red Adversary Fuzzer colliding with the Nemotron Blue Triton Healer. Real-time dual state meters track synthesis confidence, AST mutation depth, and verification convergence.
- **Secondary Dual-Col**: `MicDropDelta` (2.35x throughput leap, memory efficiency gains) paired with `VerificationImpact` (formal invariant verification proof and GitHub PR attestation trigger).
- **Bottom Stream**: `TerminalWindow` — Dedicated real-time streaming console showing sub-millisecond SSE logs with color-coded severity tags.

#### Stage 02: 132-SM Silicon Die & 32-Warp Matrix
- **Left Hero**: `HopperDieTopology` — Holographic interactive silicon die rendering all 132 Streaming Multiprocessors across 8 GPCs, flanked by 4 HBM3e stacks and the central 50MB L2 crossbar. Clicking any SM core isolates its telemetry; SM 14 dynamically lights up in plasma coral during fault injection.
- **Right Hero**: `WarpVisualizer` — Real-time SIMT warp execution matrix inspecting the 32 individual thread lanes of Warp 0. Clearly visualizes active compute lanes (`LANES 0..22`), masked tail lanes (`LANES 23..31`), and `@p0` hardware predication registers preventing memory boundary trips.
- **Bottom Unit**: `NsightTelemetryHud` — High-precision hardware counters (SM Occupancy, FP8 Tensor TFLOPS, Memory Coalescing Ratio).

#### Stage 03: AST Diff & PTX Disassembly Inspector
- **Left Column**: High-resolution syntax-highlighted side-by-side code diff contrasting the vulnerable unmasked CUDA C++ kernel against the autonomous hardened Triton Python kernel.
- **Right Column**: Interactive PTX ISA Disassembly highlighting the critical `@p0 st.global.f32` predication instruction that eliminates the GPU MMU page trap without warp divergence penalty.
- **Integrated Console**: Collapsible proving console for instant trace reproduction.

#### Stage 04: Nsight Profiler & 4-Tier Memory Waterfall
- **Top Panoramic HUD**: `NsightTelemetryHud` displaying multi-metric cluster telemetry (Compute Warp Dispatch, Register Pressure, HBM3e Saturation).
- **Bottom Dual-Col**: `SiliconMemoryWaterfall` tracing byte traversal across the 4 physical tiers:
  1. HBM3e High-Bandwidth Memory (3.35 TB/s)
  2. 50MB Unified L2 Cache Crossbar
  3. 228KB per-SM Shared Memory / SRAM L1
  4. 4th-Gen Tensor Core Execution Units
  Coupled with `VerificationImpact` for attestation signoff.

## 6. Implementation Architecture

### 6.1 Top-Level Stage Orchestration (`frontend/src/App.jsx`)
```jsx
import React, { useState } from 'react';
import ExecutiveCommandBar from './components/ExecutiveCommandBar';
import RedBlueArena from './components/RedBlueArena';
import HopperDieTopology from './components/HopperDieTopology';
import WarpVisualizer from './components/WarpVisualizer';
import CodeDiffInspector from './components/CodeDiffInspector';
import TerminalWindow from './components/TerminalWindow';
import NsightTelemetryHud from './components/NsightTelemetryHud';
import SiliconMemoryWaterfall from './components/SiliconMemoryWaterfall';
import MicDropDelta from './components/MicDropDelta';
import VerificationImpact from './components/VerificationImpact';
import Footer from './components/Footer';
import AttestationModal from './components/AttestationModal';
import { sound } from './utils/audio';

export default function App() {
  const [selectedHardware, setSelectedHardware] = useState('NVIDIA Hopper H100 SXM5');
  const [selectedFixture, setSelectedFixture] = useState('swiglu');
  const [selectedSm, setSelectedSm] = useState(14);
  const [seqLen, setSeqLen] = useState(1023);
  const [isRunning, setIsRunning] = useState(false);
  const [currentStage, setCurrentStage] = useState('IDLE');
  const [progress, setProgress] = useState(0);

  const [logs, setLogs] = useState([]);
  const [tavilyData, setTavilyData] = useState(null);
  const [redData, setRedData] = useState(null);
  const [blueData, setBlueData] = useState(null);
  const [metrics, setMetrics] = useState(null);
  const [attestation, setAttestation] = useState('0x7f56b9fe02089399');
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [activeWorkbenchTab, setActiveWorkbenchTab] = useState('collider');

  const addLog = (text, type = 'info') => {
    const timestamp = new Date().toLocaleTimeString();
    setLogs(prev => [...prev, { text: `[${timestamp}] ${text}`, type }]);
  };

  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);
    setTavilyData(null);
    setRedData(null);
    setBlueData(null);
    setMetrics(null);

    addLog(`[INIT] Engaging Aegis-Kernel Autonomous Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'TAVILY_RECON') {
          setCurrentStage('TAVILY');
          addLog(data.message, 'info');
        } else if (data.stage === 'TAVILY_RECON_COMPLETE') {
          setTavilyData(data.tavily_intel);
          addLog(`[TAVILY ORACLE] Verified 128-bit vector alignment & PTX ISA specs for Hopper SM_90a.`, 'success');
        } else if (data.stage === 'RED_ATTACK_SYNTHESIS') {
          setCurrentStage('RED_ATTACK');
          addLog(data.message, 'info');
        } else if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          setRedData(data.red_attack);
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
          addLog(data.red_attack.stack_trace, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(data.message, 'info');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setBlueData(data.blue_patch);
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'DUAL_VERIFY') {
          setCurrentStage('VERIFYING');
          addLog(data.message, 'info');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(data.message, 'success');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={(val) => {
          setSeqLen(val);
          addLog(`[SLIDER] Dynamic sequence length set to ${val} tokens`, 'info');
        }}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <main className="aegis-workbench-container">
        {/* Stage Navigation Strip */}
        <nav className="workbench-stage-nav-bar font-mono" aria-label="Workbench Stages">
          <div className="stage-nav-tabs">
            {[
              { id: 'collider', num: '01', label: 'Red vs Blue Collider & Delta' },
              { id: 'silicon', num: '02', label: '132-SM Die & 32-Warp Matrix' },
              { id: 'code', num: '03', label: 'AST Diff & PTX Disassembly' },
              { id: 'telemetry', num: '04', label: 'Nsight Profiler & Memory Waterfall' }
            ].map((tab) => (
              <button 
                key={tab.id}
                className={`stage-nav-btn ${activeWorkbenchTab === tab.id ? 'active' : ''}`}
                onClick={() => { sound.playClick(); setActiveWorkbenchTab(tab.id); }}
              >
                <span className="nav-tag-num">{tab.num}</span>
                <span>{tab.label}</span>
              </button>
            ))}
          </div>

          <div className="stage-nav-telemetry">
            <span className="nav-telemetry-badge">
              <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
              {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
            </span>
          </div>
        </nav>

        {/* Dynamic Uncongested Workbench Canvas */}
        <section className="workbench-spacious-view">
          {activeWorkbenchTab === 'collider' && (
            <div className="tab-view-container tab-view-fade">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
                redData={redData}
                blueData={blueData}
              />
              <div className="spacious-two-col">
                <MicDropDelta metrics={metrics} selectedFixture={selectedFixture} />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
              <TerminalWindow logs={logs} onClear={() => setLogs([])} />
            </div>
          )}

          {activeWorkbenchTab === 'silicon' && (
            <div className="tab-view-container tab-view-fade">
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                  seqLen={seqLen}
                />
              </div>
              <NsightTelemetryHud metrics={metrics} selectedHardware={selectedHardware} />
            </div>
          )}

          {activeWorkbenchTab === 'code' && (
            <div className="tab-view-container tab-view-fade">
              <CodeDiffInspector selectedFixture={selectedFixture} blueData={blueData} />
              <TerminalWindow logs={logs} onClear={() => setLogs([])} />
            </div>
          )}

          {activeWorkbenchTab === 'telemetry' && (
            <div className="tab-view-container tab-view-fade">
              <NsightTelemetryHud metrics={metrics} selectedHardware={selectedHardware} />
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall metrics={metrics} selectedHardware={selectedHardware} />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
            </div>
          )}
        </section>
      </main>

      <Footer />
      <AttestationModal 
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        fixtureId={selectedFixture}
        hardwareTarget={selectedHardware}
        attestationHash={attestation}
      />
    </div>
  );
}
```

### 6.2 Interactive Silicon Die & Warp SIMT Predication Engine
The `HopperDieTopology` component visualizes the 132 SM layout grouped into 8 GPCs with animated 3.35 TB/s L2 cache crossbars. When SM 14 encounters an out-of-bounds index, it triggers a localized plasma-red radiation glow while neighboring SMs continue operating. The coordinated `WarpVisualizer` maps out each of the 32 SIMT threads:
- Threads `0` through `22` show active green execution vectors (`ACTIVE [FP32]`).
- Threads `23` through `31` show `@p0` predicated masking (`MASKED [PREDICATED ZERO-OVERHEAD]`), demonstrating hardware-level memory safety.
