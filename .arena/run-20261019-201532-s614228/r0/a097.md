# Aegis-Kernel UI-UX Architecture & Design System Specification

## 1. Executive Summary & Vision: The Finished Instrument
**Aegis-Kernel** is an autonomous GPU invariant and kernel proving workbench engineered for the Nebius x NVIDIA Global AI Hackathon '26. The platform pairs a red-teaming adversarial fuzzer (**Nemotron Red**, 3B Ultra) with an automated Triton kernel synthesis healer (**Nemotron Blue**, 70B) in a closed-loop execution proving pipeline targeting NVIDIA Hopper GH100 (132 Streaming Multiprocessors, SM_90a) and Blackwell B200 (160 SMs, SM_100) hardware targets.

The finished UI/UX architecture transforms the dense, multi-faceted proving cycle into an elite, spatial, hardware-authentic supercomputer cockpit. Rather than a cramped SaaS dashboard or a superficial palette swap, the interface provides:
1. **Uncluttered Spatial Ergonomics**: An intelligent 4-Stage Spatial Stage Navigator coupled with an Executive Command Cockpit that decouples heavy analytical views into clear, focused workspaces with generous breathing room (24px grid gutters, 16px internal padding, clean negative space).
2. **Cyber-Physical Supercomputer Visual Language**: Deep obsidian silicon voids (`#03060D`), laser emerald traces (`#00FF88`), plasma coral adversary alerts (`#FF0055`), and quantum cyan telemetry conduits (`#00F0FF`) with hardware-accelerated glowing particle reactors and subtle SVG circuit grid backdrops.
3. **Uncompromising Hardware Authenticity**: Direct, interactive visualization of physical GPU architecture—including the full 132-SM die floorplan partitioned across 8 GPCs, SIMT 32-thread warp execution matrices showing hardware predication register states (`@p0`), synchronized PTX assembly ISA disassemblies, Nsight 100KHz telemetry meters, and a 4-tier silicon memory waterfall (HBM3e -> L2 Crossbar -> SM Shared Memory -> Tensor Core ALUs).
4. **Interactive Proving Ground**: Real-time parameter scrubbers (dynamic sequence length tensor slider with automatic ragged-boundary detection $seq\_len \pmod{32} \neq 0$), dynamic hardware target selection (GH100 / L40S / B200), workload switching (Fused SwiGLU, Vector RMSNorm, Online Softmax), and reactive Server-Sent Events (SSE) telemetry visualization.

---

## 2. Assumptions
1. **Target Runtime Stack**: Built on React 19 + Tailwind CSS + Lucide React icon system, with Web Audio API synthesis for tactical audio cues.
2. **Host Resolution & Ergonomics**: Primary design target is modern desktop displays ($1920 \times 1080$ and above, scaling cleanly down to $1280 \times 800$ laptops via CSS flex/grid responsiveness and zero horizontal spill).
3. **Backend Communication**: Real-time proving telemetry streams over Server-Sent Events (SSE) via `/api/v1/execute/{fixture_id}?hardware_target={target}` with robust client-side simulation fallbacks when disconnected.
4. **Microarchitectural Scope**: NVIDIA Hopper GH100 serves as the primary hardware reference (132 SMs, 8 GPCs, 60MB L2, 228KB SRAM/SM, 3.35 TB/s HBM3e). Blackwell B200 scaling dynamically increases SM count to 160 and bandwidth to 8.0 TB/s.

## 4. Architectural Trade-Off Analysis

| Architectural Decision | Chosen Implementation | Alternative Rejected | Justification & Impact |
| :--- | :--- | :--- | :--- |
| **Viewport Layout Strategy** | **Decoupled 4-Stage Spatial Stage Navigator** | Monolithic 8-widget single-page dashboard | Eliminates visual congestion and 600px scrolling fatigue while allowing each stage to breathe with deep technical focus. |
| **Color & Material System** | **Cyber-Physical Quantum Supercomputer Palette** | Monochromatic grayscale or generic dark theme | Conveys elite HPC cleanroom diagnostics using authentic NVIDIA green and high-contrast plasma indicators. |
| **Warp Representation** | **Discrete 32-Lane SIMT Register Grid** | High-level summary charts | Directly exposes thread-level out-of-bounds memory divergence and `@p0` hardware register masking for kernel developers. |
| **Memory Dataflow** | **Hierarchical Physical Bandwidth Waterfall** | Standard bar chart comparisons | Explicitly visualizes data movement across physical silicon tiers (3.35 TB/s HBM3e down to SRAM registers). |

## 6. Comprehensive Component Architecture & Code Implementation

### 6.1 Top-Level Spatial Layout (`frontend/src/App.jsx`)
The core application coordinator orchestrates the global state, SSE event pipeline, sound synthesis, and the 4-stage spatial workbench.

```jsx
import React, { useState } from 'react';
import ExecutiveCommandBar from './components/ExecutiveCommandBar';
import RedBlueArena from './components/RedBlueArena';
import HopperDieTopology from './components/HopperDieTopology';
import WarpVisualizer from './components/WarpVisualizer';
import CodeDiffInspector from './components/CodeDiffInspector';
import TerminalWindow from './components/TerminalWindow';
import NsightTelemetryHud from './components/NsightTelemetryHud';
import SiliconMemoryWaterfall from './components/SiliconMemoryWaterfall';
import MicDropDelta from './components/MicDropDelta';
import VerificationImpact from './components/VerificationImpact';
import Footer from './components/Footer';
import AttestationModal from './components/AttestationModal';
import { sound } from './utils/audio';

export default function App() {
  const [selectedHardware, setSelectedHardware] = useState('NVIDIA Hopper H100 SXM5');
  const [selectedFixture, setSelectedFixture] = useState('swiglu');
  const [selectedSm, setSelectedSm] = useState(14);
  const [seqLen, setSeqLen] = useState(1023);
  const [isRunning, setIsRunning] = useState(false);
  const [currentStage, setCurrentStage] = useState('IDLE');
  const [progress, setProgress] = useState(0);

  const [logs, setLogs] = useState([]);
  const [tavilyData, setTavilyData] = useState(null);
  const [redData, setRedData] = useState(null);
  const [blueData, setBlueData] = useState(null);
  const [metrics, setMetrics] = useState(null);
  const [attestation, setAttestation] = useState('0x7f56b9fe02089399');
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [activeWorkbenchTab, setActiveWorkbenchTab] = useState('collider');

  const addLog = (text, type = 'info') => {
    const timestamp = new Date().toLocaleTimeString();
    setLogs(prev => [...prev, { text: `[${timestamp}] ${text}`, type }]);
  };

  const handleClearLogs = () => {
    sound.playClick();
    setLogs([]);
  };

  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);
    setTavilyData(null);
    setRedData(null);
    setBlueData(null);
    setMetrics(null);

    addLog(`[INIT] Engaging Aegis-Kernel Autonomous Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'TAVILY_RECON') {
          setCurrentStage('TAVILY');
          addLog(data.message, 'info');
        } else if (data.stage === 'TAVILY_RECON_COMPLETE') {
          setTavilyData(data.tavily_intel);
          addLog(`[TAVILY ORACLE] Verified 128-bit vector alignment & PTX ISA specs for Hopper SM_90a.`, 'success');
        } else if (data.stage === 'RED_ATTACK_SYNTHESIS') {
          setCurrentStage('RED_ATTACK');
          addLog(data.message, 'info');
        } else if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          setRedData(data.red_attack);
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
          addLog(data.red_attack.stack_trace, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(data.message, 'info');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setBlueData(data.blue_patch);
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'DUAL_VERIFY') {
          setCurrentStage('VERIFYING');
          addLog(data.message, 'info');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(data.message, 'success');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      {/* Executive Command Cockpit */}
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={(val) => {
          setSeqLen(val);
          addLog(`[SLIDER] Dynamic sequence length set to ${val} tokens`, 'info');
        }}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <div className="aegis-workbench-container">
        {/* Spatial Workbench Stage Navigation Bar */}
        <div className="workbench-stage-nav-bar font-mono">
          <div className="stage-nav-tabs">
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'collider' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('collider'); }}
            >
              <span className="nav-tag-num">01</span>
              <span>Red vs Blue Collider & Delta</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'silicon' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('silicon'); }}
            >
              <span className="nav-tag-num">02</span>
              <span>132-SM Die & 32-Warp Matrix</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'code' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('code'); }}
            >
              <span className="nav-tag-num">03</span>
              <span>AST Diff & PTX Disassembly</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'telemetry' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('telemetry'); }}
            >
              <span className="nav-tag-num">04</span>
              <span>Nsight Profiler & Memory Waterfall</span>
            </button>
          </div>

          <div className="stage-nav-telemetry">
            <span className="nav-telemetry-badge">
              <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
              {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
            </span>
          </div>
        </div>

        {/* Dynamic Spatial Workbench Content View */}
        <div className="workbench-spacious-view">
          {/* TAB 1: RED VS BLUE COLLIDER & MIC-DROP DELTA */}
          {activeWorkbenchTab === 'collider' && (
            <div className="tab-view-container tab-view-fade">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
                redData={redData}
                blueData={blueData}
              />

              <div className="spacious-two-col">
                <MicDropDelta 
                  metrics={metrics} 
                  selectedFixture={selectedFixture} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>

              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {/* TAB 2: SILICON DIE & 32-WARP EXECUTION MATRIX */}
          {activeWorkbenchTab === 'silicon' && (
            <div className="tab-view-container tab-view-fade">
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                />
              </div>

              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
            </div>
          )}

          {/* TAB 3: CODE DIFF & PTX DISASSEMBLY */}
          {activeWorkbenchTab === 'code' && (
            <div className="tab-view-container tab-view-fade">
              <CodeDiffInspector 
                selectedFixture={selectedFixture} 
                blueData={blueData} 
              />
              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {/* TAB 4: NSIGHT TELEMETRY & SILICON MEMORY WATERFALL */}
          {activeWorkbenchTab === 'telemetry' && (
            <div className="tab-view-container tab-view-fade">
              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall 
                  metrics={metrics} 
                  selectedHardware={selectedHardware} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
            </div>
          )}
        </div>
      </div>

      <Footer />
      <AttestationModal 
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        fixtureId={selectedFixture}
        hardwareTarget={selectedHardware}
        attestationHash={attestation}
      />
    </div>
  );
}
```

### 6.2 Executive Command Cockpit (`frontend/src/components/ExecutiveCommandBar.jsx`)
Houses top-level system controls, target hardware selection, dynamic tensor length slider, and execution DAG stage monitors.

```jsx
import React, { useState } from 'react';
import { Shield, Cpu, ChevronDown, Volume2, VolumeX, Sparkles, GitPullRequest, Play, Loader2, Sliders, AlertTriangle, ShieldCheck, CheckCircle2 } from 'lucide-react';
import { sound } from '../utils/audio';

export default function ExecutiveCommandBar({
  selectedHardware,
  onSelectHardware,
  selectedFixture,
  onSelectFixture,
  isRunning,
  currentStage,
  progress,
  onRun,
  seqLen,
  onSeqLenChange,
  onOpenPitch,
  onOpenPrModal
}) {
  const [isMuted, setIsMuted] = useState(false);
  const [hwDropdownOpen, setHwDropdownOpen] = useState(false);

  const hardwareOptions = [
    { id: 'NVIDIA Hopper H100 SXM5', label: 'Hopper H100 SXM5', spec: '80GB · SM_90a · 3.35 TB/s' },
    { id: 'NVIDIA Ada Lovelace L40S', label: 'Ada Lovelace L40S', spec: '48GB · SM_89 · 864 GB/s' },
    { id: 'NVIDIA Blackwell B200', label: 'Blackwell B200', spec: '192GB · SM_100 · 8.0 TB/s' }
  ];

  const currentHw = hardwareOptions.find(h => h.id === selectedHardware) || hardwareOptions[0];

  const workloads = [
    { id: 'swiglu', name: 'Fused SwiGLU', model: 'LLaMA-3 · Mistral', fault: 'SIGSEGV 139', speedup: '2.35x' },
    { id: 'rmsnorm', name: 'Vector RMSNorm', model: 'Qwen-2.5 · DeepSeek', fault: 'Silent SDC', speedup: '2.33x' },
    { id: 'softmax', name: 'Online Softmax', model: 'FlashAttention-v3', fault: 'NaN Overflow', speedup: '2.27x' }
  ];

  const stages = [
    { id: 'TAVILY', label: '01 Tavily Recon', active: ['INIT', 'TAVILY', 'TAVILY_RECON', 'TAVILY_RECON_COMPLETE'] },
    { id: 'RED_ATTACK', label: '02 Red Fuzzer', active: ['RED_ATTACK', 'RED_ATTACK_SYNTHESIS'] },
    { id: 'SANDBOX_FAIL', label: '03 Sandbox Crash', active: ['SANDBOX_FAIL', 'SANDBOX_RED_EXECUTE'] },
    { id: 'BLUE_SYNTHESIS', label: '04 Nemotron Blue', active: ['BLUE_SYNTHESIS', 'BLUE_SYNTHESIS_COMPLETE'] },
    { id: 'VERIFYING', label: '05 Dual Invariant', active: ['VERIFYING', 'DUAL_VERIFY', 'COMPLETE'] }
  ];

  const isRagged = seqLen % 32 !== 0;
  const tailThreads = seqLen % 32;

  const handleToggleSound = () => {
    const muted = sound.toggleMute();
    setIsMuted(muted);
    if (!muted) sound.playClick();
  };

  const handleSelectHw = (hwId) => {
    sound.playClick();
    onSelectHardware(hwId);
    setHwDropdownOpen(false);
  };

  const handleSelectWl = (wlId) => {
    if (isRunning) return;
    sound.playClick();
    onSelectFixture(wlId);
  };

  const getStageStatus = (stg) => {
    if (!isRunning && currentStage === 'IDLE') return 'idle';
    if (stg.active.includes(currentStage)) return 'active';
    const activeIdx = stages.findIndex(s => s.active.includes(currentStage));
    const thisIdx = stages.findIndex(s => s.id === stg.id);
    if (activeIdx > thisIdx || currentStage === 'COMPLETE') return 'completed';
    return 'pending';
  };

  return (
    <header className="exec-cockpit-header">
      <div className="exec-top-strip">
        <div className="exec-brand-lockup">
          <div className="exec-brand-shield">
            <Shield size={20} className="text-nvidia animate-pulse-glow" />
          </div>
          <div>
            <div className="flex items-center gap-2">
              <span className="exec-brand-title font-mono font-bold tracking-wider">AEGIS-KERNEL</span>
              <span className="exec-badge-edition font-mono">NEBIUS × NVIDIA '26</span>
            </div>
            <span className="exec-brand-subtitle text-secondary">Autonomous GPU Invariant & Kernel Proving Workbench</span>
          </div>
        </div>

        <div className="exec-workload-selector">
          {workloads.map((wl) => (
            <button
              key={wl.id}
              onClick={() => handleSelectWl(wl.id)}
              disabled={isRunning}
              className={`exec-wl-btn ${selectedFixture === wl.id ? 'active' : ''}`}
            >
              <div className="flex items-center justify-between gap-3">
                <span className="font-mono font-bold text-xs">{wl.name}</span>
                <span className="exec-wl-speedup font-mono">{wl.speedup}</span>
              </div>
              <div className="flex items-center justify-between text-[10px] text-tertiary mt-0.5">
                <span>{wl.model}</span>
                <span className="text-coral font-mono">{wl.fault}</span>
              </div>
            </button>
          ))}
        </div>

        <div className="exec-actions-cluster">
          <div className="relative">
            <button
              onClick={() => setHwDropdownOpen(!hwDropdownOpen)}
              className="exec-hw-dropdown-btn font-mono"
            >
              <Cpu size={14} className="text-nvidia" />
              <span>{currentHw.label}</span>
              <ChevronDown size={12} className="text-tertiary" />
            </button>
            {hwDropdownOpen && (
              <div className="exec-hw-menu">
                {hardwareOptions.map((hw) => (
                  <button
                    key={hw.id}
                    onClick={() => handleSelectHw(hw.id)}
                    className={`exec-hw-item ${selectedHardware === hw.id ? 'active' : ''}`}
                  >
                    <div className="font-mono font-bold text-xs text-primary">{hw.label}</div>
                    <div className="font-mono text-[10px] text-tertiary">{hw.spec}</div>
                  </button>
                ))}
              </div>
            )}
          </div>

          <button
            onClick={handleToggleSound}
            className="exec-icon-btn"
            title={isMuted ? 'Unmute Audio' : 'Mute Audio'}
          >
            {isMuted ? <VolumeX size={15} className="text-muted" /> : <Volume2 size={15} className="text-nvidia" />}
          </button>

          <button
            onClick={onOpenPitch}
            className="exec-pitch-btn font-mono"
          >
            <Sparkles size={14} className="text-nvidia" />
            <span>EXECUTIVE PITCH</span>
          </button>

          <button
            onClick={onOpenPrModal}
            className="exec-pr-btn font-mono"
          >
            <GitPullRequest size={14} className="text-cyan" />
            <span>PR SUBMISSION</span>
          </button>
        </div>
      </div>

      <div className="exec-bottom-strip">
        <div className="exec-slider-pod">
          <div className="flex items-center justify-between text-xs font-mono mb-1">
            <span className="flex items-center gap-1.5 text-secondary">
              <Sliders size={12} className="text-amber" />
              <span>DYNAMIC TENSOR SEQ_LEN</span>
            </span>
            <div className="flex items-center gap-2">
              <span className="font-bold text-primary">{seqLen}</span>
              <span className={`exec-ragged-pill font-mono ${isRagged ? 'ragged' : 'aligned'}`}>
                {isRagged ? `RAGGED TAIL: +${tailThreads} THREADS` : 'ALIGNED (MULTIPLE OF 32)'}
              </span>
            </div>
          </div>
          <input
            type="range"
            min={128}
            max={4096}
            step={1}
            value={seqLen}
            onChange={(e) => onSeqLenChange(parseInt(e.target.value, 10))}
            className="exec-range-slider"
          />
        </div>

        <div className="exec-dag-tracker">
          {stages.map((stg) => {
            const status = getStageStatus(stg);
            return (
              <div key={stg.id} className={`exec-dag-step ${status}`}>
                <div className="dag-dot-pulse"></div>
                <span className="font-mono text-[11px] font-semibold">{stg.label}</span>
              </div>
            );
          })}
        </div>

        <button
          onClick={onRun}
          disabled={isRunning}
          className={`exec-launch-btn font-mono ${isRunning ? 'running' : ''}`}
        >
          {isRunning ? (
            <>
              <Loader2 size={16} className="animate-spin text-nvidia" />
              <span>PROVING IN PROGRESS... {progress}%</span>
            </>
          ) : (
            <>
              <Play size={16} className="fill-current text-void" />
              <span>ENGAGE PROVING GROUND</span>
            </>
          )}
        </button>
      </div>
    </header>
  );
}
```

### 6.3 32-Warp SIMT Matrix Visualizer (`frontend/src/components/WarpVisualizer.jsx`)
Renders the microarchitectural thread lanes of Warp 0, showing hardware out-of-bounds memory divergence alongside hardened `@p0` predication masks.

```jsx
import React, { useState } from 'react';
import { Layers, ShieldCheck, AlertTriangle, Cpu, Terminal, ArrowRight } from 'lucide-react';
import { sound } from '../utils/audio';

export default function WarpVisualizer({ selectedFixture, isRunning, currentStage }) {
  const [selectedLane, setSelectedLane] = useState(17);
  const [activeMode, setActiveMode] = useState('hardened');

  const isSwiglu = selectedFixture === 'swiglu';
  const isRmsnorm = selectedFixture === 'rmsnorm';

  const boundaryLimit = isSwiglu ? 17 : (isRmsnorm ? 24 : 20);
  const isCrashStage = currentStage === 'SANDBOX_FAIL' || currentStage === 'RED_ATTACK';
  const effectiveMode = isCrashStage ? 'vulnerable' : activeMode;

  const handleSelectLane = (idx) => {
    sound.playClick();
    setSelectedLane(idx);
  };

  const handleToggleMode = (mode) => {
    sound.playClick();
    setActiveMode(mode);
  };

  const selectedThreadInfo = {
    laneId: selectedLane,
    isValid: selectedLane < boundaryLimit,
    address: `0x7F4E82${(selectedLane * 4).toString(16).padStart(2, '0').toUpperCase()}`,
    vulnerableState: selectedLane < boundaryLimit 
      ? 'ACTIVE (Coalesced 32-bit Half2 Vector Load)' 
      : 'CRITICAL OOB FAULT: Bus Memory Address Segmentation Crash (SIGSEGV 139)',
    hardenedState: selectedLane < boundaryLimit 
      ? 'ACTIVE (@p0 == 1, Vectorized Half2 Load in SRAM)' 
      : 'PREDICATED (@p0 == 0, Hardware Suppressed, 0.0 Zero Register Invariant)',
    predicateReg: selectedLane < boundaryLimit ? '@p0 = 1 (EXECUTE)' : '@p0 = 0 (MASKED / SUPPRESSED)',
    ptxInstruction: selectedLane < boundaryLimit 
      ? 'ld.global.nc.v2.f16 {%r1, %r2}, [%rd3];' 
      : (effectiveMode === 'vulnerable' ? 'ld.global.v2.f16 (Bus Panic)' : '@p0 ld.global.nc.v2.f16 (0 Cycle Mask)'),
    registerValue: selectedLane < boundaryLimit ? '0.8412 + 0.4219j' : (effectiveMode === 'vulnerable' ? 'CORRUPTED MEMORY EXCEPTION' : '0.0000 (Hardware Zero Invariant)')
  };

  return (
    <div className="warp-quantum-card">
      <div className="warp-top-header">
        <div className="warp-title-lockup">
          <div className="warp-halo-icon">
            <Layers size={16} className="text-nvidia" />
          </div>
          <div>
            <div className="flex items-center gap-2">
              <span className="warp-title font-mono font-bold">SIMT WARP 0 // 32-THREAD EXECUTION MATRIX</span>
              <span className="warp-arch-tag font-mono">Hopper SM_90a SIMT Sub-Core</span>
            </div>
            <span className="warp-subtitle text-tertiary">Real-Time Lockstep Instruction Scheduler & Hardware Predication</span>
          </div>
        </div>

        <div className="warp-switch-cluster font-mono">
          <button
            onClick={() => handleToggleMode('vulnerable')}
            className={`warp-mode-pill font-mono ${effectiveMode === 'vulnerable' ? 'vulnerable' : ''}`}
          >
            <AlertTriangle size={12} className="inline mr-1" />
            VULNERABLE (UNMASKED)
          </button>
          <button
            onClick={() => handleToggleMode('hardened')}
            className={`warp-mode-pill font-mono ${effectiveMode === 'hardened' ? 'hardened' : ''}`}
          >
            <ShieldCheck size={12} className="inline mr-1" />
            HARDENED (@p0 PREDICATED)
          </button>
        </div>
      </div>

      <div className="warp-lanes-matrix">
        {Array.from({ length: 32 }).map((_, idx) => {
          const isValid = idx < boundaryLimit;
          const isSelected = idx === selectedLane;
          let laneClass = 'lane-active';

          if (!isValid) {
            laneClass = effectiveMode === 'vulnerable' ? 'lane-fault' : 'lane-predicated';
          }

          return (
            <div
              key={idx}
              onClick={() => handleSelectLane(idx)}
              className={`warp-lane-box ${laneClass} ${isSelected ? 'selected' : ''}`}
            >
              <div className="lane-header">
                <span className="lane-id">T{idx.toString().padStart(2, '0')}</span>
                <span className="lane-status-dot"></span>
              </div>
              <div className="lane-body font-mono">
                {isValid ? 'VALID' : (effectiveMode === 'vulnerable' ? 'OOB' : '@p0=0')}
              </div>
            </div>
          );
        })}
      </div>

      <div className="warp-thread-inspector font-mono">
        <div className="thread-inspector-header">
          <span className="text-nvidia">THREAD LANE T{selectedThreadInfo.laneId.toString().padStart(2, '0')} HARDWARE TELEMETRY</span>
          <span className="text-tertiary">PHYSICAL ADDRESS: {selectedThreadInfo.address}</span>
        </div>
        <div className="thread-inspector-grid">
          <div className="inspector-cell">
            <span className="cell-label">PREDICATION REGISTER</span>
            <span className={`cell-val font-bold ${selectedThreadInfo.isValid ? 'text-nvidia' : (effectiveMode === 'vulnerable' ? 'text-coral' : 'text-cyan')}`}>
              {selectedThreadInfo.predicateReg}
            </span>
          </div>
          <div className="inspector-cell">
            <span className="cell-label">SCHEDULED PTX INSTRUCTION</span>
            <span className="cell-val text-primary text-xs">{selectedThreadInfo.ptxInstruction}</span>
          </div>
          <div className="inspector-cell">
            <span className="cell-label">REGISTER VECTOR VALUE</span>
            <span className={`cell-val ${selectedThreadInfo.isValid ? 'text-nvidia' : (effectiveMode === 'vulnerable' ? 'text-coral' : 'text-secondary')}`}>
              {selectedThreadInfo.registerValue}
            </span>
          </div>
          <div className="inspector-cell">
            <span className="cell-label">LANE EXECUTION STATE</span>
            <span className={`cell-val text-xs ${selectedThreadInfo.isValid ? 'text-nvidia' : (effectiveMode === 'vulnerable' ? 'text-coral' : 'text-cyan')}`}>
              {effectiveMode === 'vulnerable' ? selectedThreadInfo.vulnerableState : selectedThreadInfo.hardenedState}
            </span>
          </div>
        </div>
      </div>
    </div>
  );
}
```
