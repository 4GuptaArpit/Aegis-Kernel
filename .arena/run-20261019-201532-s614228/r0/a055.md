# Aegis-Kernel UI-UX Architecture & Design System

## Executive Summary & Design Thesis

**Aegis-Kernel** is an autonomous GPU invariant and kernel proving workbench engineered for the Nebius x NVIDIA Global AI Hackathon '26. The platform proves mathematical invariants and verifies autonomous self-healing loops between the **Nemotron Red Adversary fuzzer** (Nemotron 3 Ultra) and the **Nemotron Blue Triton healer** (Nemotron 70B) across NVIDIA Hopper GH100 (SM_90a) and Blackwell B200 (SM_100) hardware.

This architecture delivers an interface engineered to make NVIDIA HPC architects and Nebius infrastructure leads experience immediate visceral excitement ("GA-GA factor") while preserving the visual discipline, spacious hierarchy, and cognitive clarity required of tier-1 supercomputing software.

## 2. Worked Example: End-to-End Walkthrough of Fused SwiGLU at SeqLen 1023

To ensure mathematical and hardware rigor, every component is grounded in a concrete, realistic workload scenario:

* **Workload:** Fused SwiGLU MLP Kernel (LLaMA-3 / Mistral architecture).
* **Hardware Target:** NVIDIA Hopper GH100 SXM5 (80GB HBM3e, 132 SMs, 3.35 TB/s bandwidth).
* **Stress Parameter:** Dynamic Sequence Length $N = 1023$ (Ragged Tensor boundary condition).
* **SIMT Warp Arithmetic:**
  $$\text{Grid Blocks} = \left\lceil \frac{1023}{128} \right\rceil = 8 \text{ blocks}$$
  Each block dispatches 4 warps (128 threads). In the final block:
  - Threads 0 to 62: Valid elements ($1023 \pmod{128} = 127$).
  - Thread 63: Valid element.
  - Thread 64 to 127: **Out-of-Bounds (OOB) memory access.**
* **Nemotron Red Exploit:**
  Unmasked 128-bit vectorized float4 load:
  ```cuda
  // Unmasked CUDA Kernel - Fails on Ragged Boundary
  float4 data = *reinterpret_cast<const float4*>(in_ptr + idx * 4);
  ```
  At index 1023, the 128-bit vector fetch overshoots page boundary into unallocated VRAM, causing an MMU page fault:
  $$\text{Exit Code: } 139 \quad (\text{SIGSEGV: SM 14 MMU Page Fault at } \mathtt{0x7f9e4a200000})$$
* **Nemotron Blue Autonomous Remediation:**
  Nemotron Blue generates Triton code enforcing hardware predication:
  ```python
  # Hardened Triton Kernel with Guard Invariant
  mask = offsets < seq_len
  x = tl.load(in_ptr + offsets, mask=mask, other=0.0)
  gate = tl.load(gate_ptr + offsets, mask=mask, other=0.0)
  # SwiGLU: (x * sigmoid(x)) * gate
  hidden = (x * tl.sigmoid(x)) * gate
  tl.store(out_ptr + offsets, hidden, mask=mask)
  ```
  Lowered to PTX assembly with hardware predicate register `@p0`:
  ```ptx
  setp.lt.s32   %p0, %r_idx, %r_seqlen;
  @%p0 ld.global.v4.f32 {%f0, %f1, %f2, %f3}, [%rd_ptr];
  ```
* **Performance & Verification Outcome:**
  - Zero out-of-bounds memory accesses.
  - Latency reduced from $42.6\,\mu\text{s}$ (unstable crash loop) to $18.1\,\mu\text{s}$.
  - Speedup: **2.35x**.
  - Attestation Hash: `0x7f56b9fe02089399` (signed SHA-256 invariant certificate).

## 3. Spatial Workbench Architecture & Anti-Congestion Layout

### Resolving the Congestion Critique
The previous monolithic dashboard suffered from cognitive overload: stacked terminal windows, 132 SM blocks, warp grids, diff editors, and waterfalls all competed within a constrained vertical space. 

The Aegis-Kernel UI solves this with a **Multi-Stage Spatial Workbench**:
1. **Decoupled 4-Stage Navigation Deck:**
   - `01 Red vs Blue Collider`: Autonomous battle arena, speedup delta, dual invariant impact, and live proving terminal.
   - `02 132-SM Die & 32-Warp Matrix`: Physical Hopper GH100 floorplan alongside 32-lane SIMT execution visualizer and live telemetry HUD.
   - `03 AST Diff & PTX Disassembly`: Side-by-side CUDA vs Triton code diff and hardware predicate disassembly.
   - `04 Nsight Profiler & Memory Waterfall`: 100KHz telemetry gauges and 4-tier dataflow waterfall (HBM3e $\to$ L2 Cache $\to$ Shared Memory/SRAM $\to$ Tensor Cores).
2. **Generous Spacing & Proportional Hierarchy:**
   - 24px–32px grid gutters prevent visual crampedness.
   - Clear contrast between primary focus panels and supporting telemetry sidecars.
   - Fluid transitions with zero layout shift during proving ground runs.

The command deck integrates hardware target selection, workload presets, ragged tensor sequence length scrubbers, proving run triggers, and audio feedback controls.

import React, { useState } from 'react';

import { sound } from '../utils/audio';

  selectedHardware,

    { id: 'TAVILY', label: '01 Tavily Recon', active: ['INIT', 'TAVILY', 'TAVILY_RECON', 'TAVILY_RECON_COMPLETE'] },

    const thisIdx = stages.findIndex(s => s.id === stg.id);
    if (activeIdx > thisIdx || currentStage === 'COMPLETE') return 'completed';

        <div className="exec-workload-pills">

              >
                <div className="flex items-center justify-between gap-3">

                  <span className="exec-wl-badge font-mono">{wl.fault}</span>
                </div>

            className={`exec-launch-btn ${isRunning ? 'running' : ''}`}

            disabled={isRunning}
          >
            {isRunning ? (
              <>
                <Loader2 size={16} className="animate-spin text-obsidian" />
                <span>PROVING INVARIANT...</span>
              </>
            ) : (
              <>
                <Play size={16} className="fill-obsidian text-obsidian" />

              </>
            )}
          </button>

          <button 
            className="exec-icon-btn"
            onClick={handleToggleSound}
            title={isMuted ? "Unmute Supercomputer Audio" : "Mute Audio"}
          >
            {isMuted ? <VolumeX size={16} className="text-tertiary" /> : <Volume2 size={16} className="text-nvidia" />}
          </button>
        </div>
      </div>

      {/* Control Strip: Sequence Scrubber & Multi-Stage Collider Status */}
      <div className="exec-control-strip">
        <div className="exec-scrubber-group">
          <div className="flex items-center gap-2">
            <Sliders size={13} className="text-nvidia" />
            <span className="text-xs font-mono uppercase tracking-wider text-secondary">Stress Sequence Len:</span>
            <span className={`font-mono text-sm font-bold ${isRagged ? 'text-amber' : 'text-primary'}`}>

          {stages.map((stg) => {
            const status = getStageStatus(stg);
            return (
              <div key={stg.id} className={`exec-stage-node ${status}`}>
                <span className="exec-stage-dot"></span>
                <span className="exec-stage-label font-mono">{stg.label}</span>
              </div>
            );
          })}
        </div>
      </div>
    </header>
  );
}
