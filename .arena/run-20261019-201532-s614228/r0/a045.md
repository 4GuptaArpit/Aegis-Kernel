## 1. Executive Assumptions & Architectural Scope

1. **Target User Persona**: NVIDIA Principal HPC Engineers, Nebius Cloud Infrastructure Architects, and High-Performance Systems Evaluators who demand extreme hardware fidelity, mathematical precision, and instant visual comprehension over generic SaaS card layouts.
2. **Hardware Target Primacy**: Deep authentic modeling of **NVIDIA Hopper GH100** (TSMC 4N, 8 GPCs, 132 active Streaming Multiprocessors, 4th Gen Tensor Cores with DPX instructions, 3.35 TB/s HBM3e) and **NVIDIA Blackwell B200** (160 SMs, Dual-Die NV-HighRate 10 TB/s cross-link, 8.0 TB/s HBM3e).

## 2. Adversarial Evaluation & Vulnerability Analysis

Before constructing the architecture, we subjected the problem space and prior baseline to four critical attack vectors:

### Attack Vector 1: "The Monolith vs. Fragmented Tab Paradox"
- *The Attack*: The original design suffered from vertical stacking that overwhelmed viewport boundaries. The baseline attempted to fix this by segregating the interface into 4 disjoint tabs. An elite evaluator reviewing Stage 01 cannot correlate live warp divergence with the 132-SM die topology, destroying the feedback loop of autonomous closed-loop proving.
- *Countermeasure*: Introduce **Context-Synchronized Multi-Vector Workbenches** with a global hardware state bus. While stages isolate deep analytical depth, persistent micro-telemetry sparklines and cross-stage state indicators link adversary exploits directly to hardware silicon in real time.

### Attack Vector 2: "Hardware Surface Dressing (Skin-Deep Aesthetics)"
- *The Attack*: Many hackathon entries put green neon borders around static tables and call it "NVIDIA Supercomputer UI". Evaluators immediately notice when hardware diagrams are decorative SVGs rather than functional SIMT execution matrices.
- *Countermeasure*: Direct architectural fidelity down to the register file and PTX ISA level:
  - 132 SMs mapped directly to 8 Graphics Processing Clusters (GPCs).
  - SIMT Warp 0 represented across 32 individual 32-bit thread lanes with `@p0` hardware predication bitmasks (`0x0001FFFF` vs `0xFFFFFFFF`).
  - 4-Tier Memory Locality Waterfall tracking exact byte latency (HBM3e ~250 cycles $\to$ L2 Crossbar ~35 cycles $\to$ SM SRAM/TMA ~18 cycles $\to$ Tensor Core RF 1 cycle).

### Attack Vector 3: "Congestion vs. Information Starvation"
- *The Attack*: Stripping data to make an interface "clean" leaves HPC judges underwhelmed; cramming every gauge into one screen causes ocular fatigue.
- *Countermeasure*: **Proportional Visual Breathing Space**. Employ strict 8px harmonic spatial grid units, elevated glass-morphism panels with 0.88 opacity, high-contrast laser emerald (`#00FF88`) and plasma coral (`#FF0055`) indicators, and zero border clashes.

### Attack Vector 4: "Static Presentation Fallacy"
- *The Attack*: The UI appears alive only during simulated sweeps, offering no real-time interactive parameter inspection for boundary edge cases.
- *Countermeasure*: Interactive dynamic token scrubber ($N \in [1, 4096]$) that dynamically highlights tail warp ragged masks ($N \pmod{32} \neq 0$), hardware target switcher updating memory bandwidth rooflines on the fly, and workload selector across Fused SwiGLU, Vector RMSNorm, and Online Softmax.

## 4. Complete UI/UX Component Architecture

### 4.1 Executive Command Cockpit (`ExecutiveCommandBar.jsx`)
The cockpit sits persistently at the top of the interface, providing high-density executive control without vertical crowding:
1. **Brand Lockup**: High-contrast shield logo with pulse reactor core indicating active live proving status.
2. **Workload Selector**: Instant switching between `Fused SwiGLU` (LLaMA-3 / Mistral), `Vector RMSNorm` (Qwen-2.5 / DeepSeek), and `Online Softmax` (FlashAttention-v3). Displays baseline fault signature (`SIGSEGV 139`, `Silent SDC`, `NaN Overflow`) and proven Triton speedup.
3. **Hardware Platform Selector**: Seamless toggling between NVIDIA Hopper H100 SXM5 (80GB · SM_90a · 3.35 TB/s), Ada Lovelace L40S (48GB · SM_89 · 864 GB/s), and Blackwell B200 (192GB · SM_100 · 8.0 TB/s).
4. **Dynamic Token Sequence Scrubber**: Interactive slider ($N \in [1, 4096]$). Dynamically calculates $N \pmod{32}$. When ragged, it triggers an amber warning pill showing the exact tail thread count (`tail = N % 32`) vulnerable to OOB reads.
5. **Autonomic State Machine Progress Bar**: 5-step pipelined progression:
   $$\text{Tavily Recon (01)} \longrightarrow \text{Red Fuzzer (02)} \longrightarrow \text{Sandbox Crash (03)} \longrightarrow \text{Nemotron Blue (04)} \longrightarrow \text{Dual Invariant (05)}$$

## 5. Production Source Implementation & Integration

To achieve zero compile warnings and maximum rendering velocity, the entire architecture is wired using modern React hooks, Lucide-React vector iconography, Web Audio synthesis, and GPU-accelerated CSS keyframe transforms.

### 5.1 App Root Spatial Layout (`App.jsx`)
```jsx
import React, { useState } from 'react';
import ExecutiveCommandBar from './components/ExecutiveCommandBar';
import RedBlueArena from './components/RedBlueArena';
import HopperDieTopology from './components/HopperDieTopology';
import WarpVisualizer from './components/WarpVisualizer';
import CodeDiffInspector from './components/CodeDiffInspector';
import TerminalWindow from './components/TerminalWindow';
import NsightTelemetryHud from './components/NsightTelemetryHud';
import SiliconMemoryWaterfall from './components/SiliconMemoryWaterfall';
import MicDropDelta from './components/MicDropDelta';
import VerificationImpact from './components/VerificationImpact';
import Footer from './components/Footer';
import AttestationModal from './components/AttestationModal';
import { sound } from './utils/audio';

export default function App() {
  const [selectedHardware, setSelectedHardware] = useState('NVIDIA Hopper H100 SXM5');
  const [selectedFixture, setSelectedFixture] = useState('swiglu');
  const [selectedSm, setSelectedSm] = useState(14);
  const [seqLen, setSeqLen] = useState(1023);
  const [isRunning, setIsRunning] = useState(false);
  const [currentStage, setCurrentStage] = useState('IDLE');
  const [progress, setProgress] = useState(0);

  const [logs, setLogs] = useState([]);
  const [metrics, setMetrics] = useState(null);
  const [attestation, setAttestation] = useState('0x7f56b9fe02089399');
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [activeWorkbenchTab, setActiveWorkbenchTab] = useState('collider');

  const addLog = (text, type = 'info') => {
    const timestamp = new Date().toLocaleTimeString();
    setLogs(prev => [...prev, { text: `[${timestamp}] ${text}`, type }]);
  };

  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);

    addLog(`[INIT] Engaging Aegis Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={setSeqLen}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <main className="aegis-workbench-container">
        {/* Elastic Stage Navigation Bar */}
        <nav className="workbench-stage-nav-bar font-mono" aria-label="Workbench Stage Navigator">
          <div className="stage-nav-tabs">
            {[
              { id: 'collider', num: '01', label: 'Red vs Blue Collider & Delta' },
              { id: 'silicon', num: '02', label: '132-SM Die & 32-Warp Matrix' },
              { id: 'code', num: '03', label: 'AST Diff & PTX Disassembly' },
              { id: 'telemetry', num: '04', label: 'Nsight Profiler & Memory Waterfall' }
            ].map((tab) => (
              <button 
                key={tab.id}
                className={`stage-nav-btn ${activeWorkbenchTab === tab.id ? 'active' : ''}`}
                onClick={() => { sound.playClick(); setActiveWorkbenchTab(tab.id); }}
              >
                <span className="nav-tag-num">{tab.num}</span>
                <span>{tab.label}</span>
              </button>
            ))}
          </div>

          <div className="stage-nav-telemetry">
            <span className="nav-telemetry-badge">
              <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
              {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
            </span>
          </div>
        </nav>

        {/* Spatial Stage Content View with Breathing Room */}
        <section className="workbench-spacious-view">
          {activeWorkbenchTab === 'collider' && (
            <div className="tab-view-container tab-view-fade">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
              />
              <div className="spacious-two-col">
                <MicDropDelta metrics={metrics} selectedFixture={selectedFixture} />
                <VerificationImpact metrics={metrics} selectedFixture={selectedFixture} onOpenPrModal={() => setIsModalOpen(true)} />
              </div>
              <TerminalWindow logs={logs} onClear={() => setLogs([])} />
            </div>
          )}

          {activeWorkbenchTab === 'silicon' && (
            <div className="tab-view-container tab-view-fade">
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                />
              </div>
              <NsightTelemetryHud metrics={metrics} selectedHardware={selectedHardware} />
            </div>
          )}

          {activeWorkbenchTab === 'code' && (
            <div className="tab-view-container tab-view-fade">
              <CodeDiffInspector selectedFixture={selectedFixture} />
              <TerminalWindow logs={logs} onClear={() => setLogs([])} />
            </div>
          )}

          {activeWorkbenchTab === 'telemetry' && (
            <div className="tab-view-container tab-view-fade">
              <NsightTelemetryHud metrics={metrics} selectedHardware={selectedHardware} />
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall metrics={metrics} selectedHardware={selectedHardware} />
                <VerificationImpact metrics={metrics} selectedFixture={selectedFixture} onOpenPrModal={() => setIsModalOpen(true)} />
              </div>
            </div>
          )}
        </section>
      </main>

      <Footer />
      <AttestationModal 
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        fixtureId={selectedFixture}
        hardwareTarget={selectedHardware}
        attestationHash={attestation}
      />
    </div>
  );
}
```
