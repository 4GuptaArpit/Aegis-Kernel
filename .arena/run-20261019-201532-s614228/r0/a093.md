# Aegis-Kernel UI-UX Architecture & Design System

## Executive Overview
**Aegis-Kernel** is an autonomous GPU invariant and kernel proving workbench engineered for the **Nebius × NVIDIA Global AI Hackathon '26**. The system orchestrates an end-to-end, closed-loop formal verification collider between the **Nemotron Red Adversary** (an autonomous vulnerability fuzzer) and the **Nemotron Blue Triton Healer** (an automated kernel synthesizer) targeting NVIDIA Hopper GH100 and Blackwell B200 architectures.

This document details the complete UI-UX architecture, design tokens, spatial layout framework, and hardware-authentic components designed to eliminate visual congestion, establish clear technical hierarchy, and present NVIDIA/Nebius HPC telemetry with supercomputer-grade polish.

---

## Assumptions & Operating Parameters
1. **Target Display Environments**: Engineered primarily for widescreen workstations ($1920 \times 1080$ to $3840 \times 2160$), with responsive flex/grid adaptations down to 13-inch and 14-inch developer laptops ($1366 \times 768$ and $1440 \times 900$).
2. **Hardware Target Scope**: Fully models the NVIDIA Hopper GH100 SXM5 ($132$ Streaming Multiprocessors, $3.35\text{ TB/s}$ HBM3e, $50\text{ MB}$ L2 Cache crossbar), while maintaining selectable architectural presets for Ada Lovelace L40S ($142$ SMs, $864\text{ GB/s}$) and Blackwell B200 ($160$ SMs, $8.0\text{ TB/s}$).
3. **Execution Runtime**: Real-time event streaming via Server-Sent Events (SSE) from the FastAPI backend (`/api/v1/execute/{fixture_id}`) dispatching structured stage notifications (`INIT` $\to$ `TAVILY_RECON` $\to$ `RED_ATTACK` $\to$ `SANDBOX_FAIL` $\to$ `BLUE_SYNTHESIS` $\to$ `DUAL_VERIFY` $\to$ `COMPLETE`).

## 2. Spatial Workbench Architecture (Uncongested 4-Stage Navigator)

To resolve UI crowding, the workspace employs a decoupled **Spatial Workbench Navigator** that organizes dense supercomputer diagnostics into four focused stages:

```
+---------------------------------------------------------------------------------------------------+
| EXECUTIVE COMMAND COCKPIT: Brand Lockup | Hardware Preset | Sequence Scrubber | Proving Trigger   |
+---------------------------------------------------------------------------------------------------+
| WORKBENCH STAGE NAV: [01 Collider]  [02 Silicon Die & Warps]  [03 AST & PTX]  [04 Nsight Telemetry] |
+---------------------------------------------------------------------------------------------------+
| ACTIVE STAGE VIEWPORT (Dynamic Spacious Canvas with 24px-32px padding and explicit visual hierarchy) |
+---------------------------------------------------------------------------------------------------+
```

### Stage 01: Red vs Blue Collider & Delta
- **`RedBlueArena`**: Visual battleground contrasting Nemotron Red (OOB attack vector generator) with Nemotron Blue (Triton invariant healer), featuring animated particle collision streams.
- **`MicDropDelta` & `VerificationImpact`**: Side-by-side impact cards rendering the $2.35\times$ kernel speedup, zero-loss invariant verification score, and one-click GitHub Pull Request export trigger.
- **`TerminalWindow`**: Multi-stream execution log terminal with ANSI syntax coloring, copy buffer, and streaming auto-scroll.

### Stage 02: 132-SM Die & 32-Warp Matrix
- **`HopperDieTopology`**: Interactive SVG layout of all $132$ GH100 Streaming Multiprocessors grouped into $8$ Graphics Processing Clusters (GPCs), highlighting faulting cores (SM 14) during attack phases and illuminating all cores in emerald upon formal healing.
- **`WarpVisualizer`**: 32-thread micro-architectural SIMT inspection matrix for Warp 0, showing lockstep instruction dispatch, memory addresses (`0x7F4E82...`), and hardware predicate register states (`@p0`).
- **`NsightTelemetryHud`**: Live micro-architectural throughput summary metrics.

### Stage 03: AST Diff & PTX Disassembly
- **`CodeDiffInspector`**: Dual-pane code inspector with synchronized line numbers and syntax highlighting, allowing instantaneous comparison between:
  - Unprotected CUDA C++ (unmasked raw pointer dereferences causing `SIGSEGV 139`).
  - Hardened Triton Python (bounded block offsets `mask = offs < n_tokens`).
  - Raw PTX ISA v8.4 disassembly (`@p0 ld.global.nc.v2.f16` predicated vector loads).
- **`TerminalWindow`**: Full audit trace of compiler diagnostics and invariant generation steps.

### Stage 04: Nsight Profiler & Memory Waterfall
- **`NsightTelemetryHud`**: 6-tile real-time telemetry array rendering SM occupancy ($100\%$), Tensor Core engine throughput ($418.5\text{ TFLOPS}$), HBM3e bus saturation ($2.84\text{ TB/s}$), and register allocation pressure.
- **`SiliconMemoryWaterfall`**: 4-tier dataflow hierarchy visualizer detailing latency and bandwidth across HBM3e ($250\text{ cycles}$), L2 Cache ($35\text{ cycles}$), SM Shared Memory/TMA ($18\text{ cycles}$), and Tensor Core ALU registers ($1\text{ cycle}$).
- **`VerificationImpact`**: Production audit attestation badge and formal cryptographic proof fingerprint.

## 4. Interactive Proving Ground Controls
The **Executive Command Cockpit** provides real-time control over kernel proving runs:
1. **Hardware Target Switcher**: Dropdown supporting Hopper H100 SXM5, Ada Lovelace L40S, and Blackwell B200 with dynamic specification badges.
2. **Workload Presets**:
   - `swiglu`: Fused SwiGLU with ragged sequence length boundary vulnerabilities.
   - `rmsnorm`: Vector RMSNorm with unaligned 16-byte memory stride faults.
   - `softmax`: Online Softmax with numerical logit overflow risks.
3. **Dynamic Sequence Length Scrubber**: Interactive slider ($1$ to $4096$ tokens) with visual ragged boundary indicators (`seqLen % 32 != 0`) highlighting unaligned tail threads.
4. **Proving Collider Action**: Single-click activation triggering audio-reactive execution sounds and initiating SSE streaming from the backend.
