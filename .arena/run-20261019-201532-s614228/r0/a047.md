## 1. Executive Summary & Design Philosophy

Aegis-Kernel bridges the gap between deep hardware-level GPU invariant verification and world-class, high-energy cyber-physical design. Built for high-performance computing (HPC) engineers, kernel researchers, and hackathon judges at NVIDIA and Nebius, the interface transforms abstract mathematical verification (differential fuzzing, formal bounds checking, hardware predicate evaluation) into a luminous, physically authentic instrument.

### The Anti-Congestion Architecture
Traditional HPC and observability dashboards collapse under dense data streams, compressing telemetry into microscopic illegible tiles or endless scrolling pages. Aegis-Kernel eliminates visual friction through a **3-Tier Spatial Hierarchy**:
1. **Tier 1: Global Executive Cockpit (`ExecutiveCommandBar`)**: Fixed-height, non-scrolling command deck providing zero-latency workload selection, target hardware switching, dynamic sequence length scrubbing, and 5-stage proving pipeline progression.
2. **Tier 2: Spatial Stage Navigator (`workbench-stage-nav-bar`)**: Four dedicated, high-context acoustic workspaces that compartmentalize distinct operational phases rather than piling them into a single congested viewport.
3. **Tier 3: Contextual Stage Proving Grounds**: Spacious dual-column and multi-dimensional matrices with minimum 16px to 24px atmospheric gutters, 16px rounded glassmorphism panels, and sub-millisecond hardware-reactive micro-animations.

## 2. Open Questions & Architectural Resolutions

To ensure total determinism across all visual and computational subsystems, the following architectural ambiguities were decomposed and resolved:

### Q1: How to render 132 Streaming Multiprocessors (SMs) on standard 1080p and 1440p displays without microscopic clutter?
- **Resolution**: Rather than an unorganized grid of 132 indistinguishable squares, we structure the Hopper GH100 die topology according to physical TSMC 4N silicon layout: 8 Graphics Processing Clusters (GPCs), each housing paired SM arrays surrounding the central 50MB L2 cache crossbar highway. Each SM cell dynamically reflects 4 hardware states (`IDLE`, `DISPATCHING`, `MMU_TRAP_SM14`, `PREDICATED_HEALED`), with an interactive click-to-inspect bridge feeding Warp 0 lane telemetry.

### Q2: How to visualize SIMT warp execution and @p0 predicate masking at the individual thread level?
- **Resolution**: SIMT execution is rendered as an interactive 32-lane matrix (Warp 0, Lanes T0 through T31). A dual-mode hardware comparator toggle (`Unprotected CUDA` vs `Aegis Hardened Triton`) dynamically transforms lane states: under unmasked CUDA, lane indices exceeding the dynamic sequence boundary ($T_{lane} \ge \text{seq\_len} \pmod{32}$) trigger a pulsating crimson bus page fault; under Aegis Triton, the `@p0` hardware predicate flag evaluates in 0 clock cycles, suppressing illegal loads and holding 0.0 in register space without warp divergence penalties.

### Q3: How to maintain 60 FPS rendering during live 100 KHz Nsight telemetry streams and SSE event bursts?
- **Resolution**: All dynamic visual waveforms, reactor particles, and memory bus animations are offloaded to GPU hardware-accelerated CSS properties (`transform: translate3d`, `opacity`, `backdrop-filter`). React 19 state updates batch SSE telemetry events without triggering full-canvas DOM re-layouts.

### Q4: How to balance dark-mode readability with energetic "GA-GA" cyber-physical aesthetics?
- **Resolution**: Avoid standard dull grey-on-black palettes or noisy neon glare. The color system anchors on `#03060D` Deep Obsidian Void paired with an exact 3-point spectral harmony: NVIDIA Laser Emerald (`#00FF88`), Plasma Crimson (`#FF0055`), and Supercomputer Electric Cyan (`#00F0FF`). High-contrast typography pairs Plus Jakarta Sans (geometric executive headers) with JetBrains Mono (hardware memory offsets, assembly mnemonics, and register dumps).

### Component 1: `ExecutiveCommandBar.jsx` (Global Proving Cockpit)
- **Primary Mission**: Serves as the nerve center for proving configuration and execution control.
- **Hardware Selection Matrix**:
  - `NVIDIA Hopper H100 SXM5`: 80GB HBM3e · SM_90a · 3.35 TB/s memory bandwidth
  - `NVIDIA Ada Lovelace L40S`: 48GB GDDR6 · SM_89 · 864 GB/s memory bandwidth
  - `NVIDIA Blackwell B200`: 192GB HBM3e · SM_100 · 8.0 TB/s memory bandwidth
- **Workload Operators**:
  - **Fused SwiGLU** (`LLaMA-3 / Mistral`): Exposes raw pointer indexing and tail warp boundary overshoots (`SIGSEGV 139`).
  - **Vector RMSNorm** (`Qwen-2.5 / DeepSeek`): Exposes unaligned 128-bit vector memory loads causing Silent Data Corruption (`SDC`).
  - **Online Softmax** (`FlashAttention-v3`): Exposes unscaled logit accumulators exceeding FP16 dynamic range (`NaN Overflow`).
- **Dynamic Tensor Scrubber**:
  - Scrub range: $128 \le \text{tokens} \le 2048$.
  - Real-time warp math: Automatically computes $\text{tail} = \text{tokens} \pmod{32}$. When $\text{tail} \neq 0$, renders a vivid Crimson Ragged Boundary warning displaying the exact number of trapped out-of-bounds lanes ($32 - \text{tail}$).

### Component 2: `RedBlueArena.jsx` (Closed-Loop Adversarial Collider)
- **Primary Mission**: Visualizes the autonomous clash between the Nemotron Red attack agent and the Nemotron Blue repair agent.
- **Visual Mechanics**:
  - **Left Wing (Red Adversary)**: Bordered in luminous `#FF0055` with animated combat pulses, streaming simulated pathological hexadecimal attack vectors (`0xFF 0xFF 0xFF 0xFF` OOB dereference).
  - **Center Core (Nebius Token Factory Sandbox)**: Features a dual-ring rotating reactor core with radial particle glow that pulses synchronously during kernel execution and snaps to solid emerald upon invariant completion.
  - **Right Wing (Blue Immune Agent)**: Bordered in `#00FF88`, rendering the synthesized Triton memory clamp (`mask_m = offs_m < total_ragged_tokens; tl.load(..., mask=mask_m, other=0.0)`).

### Component 3: `HopperDieTopology.jsx` (Physical Silicon Die Architecture)
- **Primary Mission**: Authentic representation of the GH100 silicon die.
- **Architecture Mapping**:
  - 132 individual SM cores organized into dual symmetrical hemispheres flanking the central interconnect.
  - Integrated 50MB L2 Cache crossbar with bidirectional laser pulse animation simulating 3.35 TB/s coalesced traffic.
  - Quad HBM3e memory controller blocks (834 GB/s per bank) anchored at the die perimeter.
  - Interactive SM selection: Clicking any SM updates the inspection focus; SM 14 is highlighted with a critical MMU page trap warning during adversarial injection.

### Component 4: `WarpVisualizer.jsx` (SIMT 32-Thread Execution Matrix)
- **Primary Mission**: Demystifies SIMT warp execution and demonstrates zero-overhead hardware predication.
- **Thread Lane Matrix**:
  - 32 discrete thread cells (T0 to T31) rendered with custom status glyphs: `●` Active Valid, `▲` OOB Bus Fault, `◆` Hardware Predicated Masked.
  - Interactive Lane Inspector: Selecting any lane (defaulting to boundary lane T17) displays its physical 64-bit virtual memory address (`0x7F4E8244`), predicate register state (`@p0 = 0`), PTX instruction mnemonic (`@p0 ld.global.nc.v2.f16`), and hardware zero register value (`0.0000`).

### Component 5: `CodeDiffInspector.jsx` (AST Diff & PTX Disassembly)
- **Primary Mission**: Provides mathematical and assembly-level proof of the synthesized invariant.
- **Dual-Pane View Switcher**:
  - **Source Level**: Unprotected CUDA C++ baseline vs Aegis Hardened Triton Python kernel with syntax-highlighted fault lines and immune assertions.
  - **PTX Assembly Level (SM_90a)**: Naive `ld.global.v2.f16` memory bus dereference vs `@p0 ld.global.nc.v2.f16` predicated instruction showing zero cycle penalty.
  - **1-Click Copy**: Copies the full verified kernel directly to clipboard with instant audio-tactile feedback.

### Component 6: `SiliconMemoryWaterfall.jsx` (4-Tier Memory Hierarchy)
- **Primary Mission**: Traces dataflow locality improvements across all 4 physical memory tiers of Hopper GH100:
  - **Tier 1 (Global HBM3e VRAM)**: 80GB, 3.35 TB/s, ~250 cycles. Compares 3x un-fused roundtrips against 1x streamed Aegis execution (-42% bus traffic).
  - **Tier 2 (L2 Crossbar Cache)**: 50MB, 12.0 TB/s, ~35 cycles. Compares cache thrashing against 94.2% L2 hit rate.
  - **Tier 3 (SM Shared Memory / SRAM TMA)**: 228 KB/SM, 33.0 TB/s, ~18 cycles. Demonstrates in-SRAM activation fusion.
  - **Tier 4 (Tensor Core ALUs & Register File)**: 64K registers, 989 TFLOPS peak, 1 cycle. Demonstrates elevation of compute throughput to 418.5 TFLOPS with 99.4% warp efficiency.

### Component 7: `NsightTelemetryHud.jsx` (Hardware Profiling HUD)
- **Primary Mission**: Emulates NVIDIA Nsight Compute hardware profiler at 100 KHz sampling rate.
- **Key Real-Time Telemetry Metrics**:
  - SM Occupancy: `100.0%` (32 Warps/SM Active)
  - Tensor Core Engine: `418.5 TFLOPS` (Hopper 4th Gen Cores Saturated)
