# Aegis-Kernel UI-UX Architecture & Design System Specification

## 1. System Architecture & Spatial Layout

Aegis-Kernel implements a cyber-physical HPC workbench tailored for the Nebius x NVIDIA Global AI Hackathon '26. To eliminate vertical clutter and interface congestion while preserving dense hardware telemetry, the interface employs a hierarchical 4-stage spatial workbench powered by an executive command bar.

```
+----------------------------------------------------------------------------------------------------+
| EXECUTIVE COMMAND BAR: Workload Presets | Hardware Target (Hopper/Blackwell) | Dynamic SeqLen Scrubber  |
+----------------------------------------------------------------------------------------------------+
| SPATIAL STAGE NAV: [01 Collider & Delta] [02 SM Die & Warp Matrix] [03 AST & PTX] [04 Nsight HUD]  |
+----------------------------------------------------------------------------------------------------+
|                                                                                                    |
|  ACTIVE WORKBENCH STAGE VIEWPORT (Isolated 2-3 Pane Layout, Max Width 1580px, Dynamic Grid)        |
|                                                                                                    |
+----------------------------------------------------------------------------------------------------+
| TELEMETRY FOOTER & CRYPTOGRAPHIC ATTESTATION MODAL (Dual Invariant Hash, PR & Patch Generation)     |
+----------------------------------------------------------------------------------------------------+
```

### Component Topology Matrix
- **Root Viewport (`frontend/src/App.jsx`)**: Coordinates SSE streams from `/api/v1/execute/{fixture}`, orchestrates hardware and sequence parameters, and routes views between four stages.
- **Top Bar (`frontend/src/components/ExecutiveCommandBar.jsx`)**: Houses the hardware switcher, workload tabs (`swiglu`, `rmsnorm`, `softmax`), dynamic sequence length slider (1–4096), audio engine toggle, and execution trigger.
- **Stage 01 (`RedBlueArena.jsx`, `MicDropDelta.jsx`, `VerificationImpact.jsx`, `TerminalWindow.jsx`)**: The Nemotron Red Adversary fuzzer versus Nemotron Blue Triton healer proving arena, formal speedup metrics, and raw execution logs.
- **Stage 02 (`HopperDieTopology.jsx`, `WarpVisualizer.jsx`, `NsightTelemetryHud.jsx`)**: Full 132-SM physical silicon die topology paired with a 32-lane SIMT Warp execution matrix and Nsight profiler telemetry.
- **Stage 03 (`CodeDiffInspector.jsx`, `TerminalWindow.jsx`)**: Side-by-side AST comparison between unmasked CUDA C++ and hardened Triton Python, alongside PTX assembly displaying `@p0` predication flags.
- **Stage 04 (`NsightTelemetryHud.jsx`, `SiliconMemoryWaterfall.jsx`, `VerificationImpact.jsx`)**: Microarchitectural waterfall diagram detailing memory transitions across VRAM, L2, SRAM, and Tensor Core registers.

## 3. Assumptions

1. **Backend Connectivity**: The UI operates with real-time SSE streaming from `http://localhost:8000/api/v1/execute/{fixture}` when the server is active, and defaults to pre-calculated baseline telemetry states when disconnected.
2. **Target Display Resolution**: The layout is engineered for standard 1080p and 1440p engineer displays (viewport max-width: 1580px, responsive down to 1024px).
3. **Hardware Predication Mechanics**: In Triton compilation for NVIDIA SM_90a, masked loads (`tl.load(ptr, mask=mask, other=0.0)`) map directly to PTX predication register `@p0` with zero branch divergence cycles.

## 4. Design System Tokens & Foundations

### Color Tokens
- **Background Obsidian Void**: `#03060D` (98% black with deep blue undertone)
- **Surface Elevation 1 (Glass Chasis)**: `rgba(8, 14, 26, 0.82)` with `backdrop-filter: blur(16px)`
- **Surface Elevation 2 (Raised Inset)**: `rgba(13, 22, 40, 0.88)`
- **NVIDIA Laser Emerald**: `#00FF88` (Primary brand, verified invariants, active warps)
- **Plasma Coral (Adversary Fuzzer)**: `#FF0055` (Nemotron Red, OOB memory faults, bus panics)
- **Electric Cyan (Triton Architecture)**: `#00F0FF` (Memory hierarchy, PTX registers, L2 cache)
- **High-Voltage Amber**: `#FFB800` (Ragged tail warnings, sequence boundary alerts)

### Typography Hierarchy
- **UI & Display Headers**: `Plus Jakarta Sans` (400, 500, 600, 700, 800)
- **Code, ISA & Hardware Telemetry**: `JetBrains Mono` (400, 500, 700) with tabular figures (`font-variant-numeric: tabular-nums`)

### Layout Grids
- **Master Container**: Max width `1580px`, horizontal auto margin, padding `16px 24px 28px 24px`.
- **Spacious Two-Column Grid**: `display: grid; grid-template-columns: 1fr 1fr; gap: 20px; align-items: stretch;`.
- **SM Silicon Die Matrix**: 132 items arranged in an 11-column by 12-row responsive grid (`grid-template-columns: repeat(11, minmax(0, 1fr))`) with sub-GPC cluster grouping.
