### Executive Architectural Blueprint

Aegis-Kernel provides an enterprise-grade autonomous formal proving workbench demonstrating real-time closed-loop invariant testing: **Nemotron Red Adversary Fuzzer** versus **Nemotron Blue Triton Healer** targeted for **NVIDIA Hopper GH100** and **Blackwell B200** hardware.

This architecture completely eliminates visual congestion and generic SaaS dashboard paradigms. By decomposing complex GPU telemetry, silicon topologies, instruction scheduling, and adversarial proving into a **decoupled spatial workbench with an executive command cockpit**, the system grants every hardware instrument deliberate breathing room, uncompromising typographic hierarchy, and authentic supercomputer visual energy.

### 2. Design Token System & Supercomputer Visual Language

Rather than relying on basic flat backgrounds or harsh white/black swaps, the interface utilizes an authentic **Obsidian Supercomputer & Cyber-Physical Quantum** palette.

#### 2.1 Color Tokens
- **Obsidian Void Base (`--bg-void`)**: `#03060D` with subtle isometric circuit traces (`32px` grid lines at `3%` opacity) and multi-point radial energy nodes (emerald at `15% 15%`, coral at `85% 20%`, and cyan at `50% 80%`).
- **Surface Elevation (`--bg-surface`)**: `rgba(8, 14, 26, 0.82)` with backdrop blur filter (`16px`) and subtle emerald bounding borders (`rgba(0, 255, 136, 0.12)`).
- **NVIDIA Laser Emerald (`--accent-nvidia`)**: `#00FF88` (Primary brand, verified invariants, Triton immune states, 100% warp occupancy). Glow: `0 0 24px rgba(0, 255, 136, 0.45)`.
- **Crimson Plasma Coral (`--accent-coral`)**: `#FF0055` (Red adversary fuzzer, memory faults, unmasked CUDA OOB reads, SIGSEGV traps). Glow: `0 0 24px rgba(255, 0, 85, 0.45)`.
- **Quantum Electric Cyan (`--accent-cyan`)**: `#00F0FF` (HBM3e memory buses, L2 crossbar cache, 128-bit coalesced transactions). Glow: `0 0 24px rgba(0, 240, 255, 0.40)`.
- **Amber Warning (`--accent-amber`)**: `#FFB800` (Dynamic sequence length scrubbers, tail warp ragged warnings).

#### 2.2 Typography Hierarchy
- **Primary Interface**: `Plus Jakarta Sans` (400, 500, 600, 700, 800) for clean, high-contrast, modern display.
- **Hardware Telemetry & Code**: `JetBrains Mono` (400, 500, 600, 700) for all hexadecimal register dumps, PTX ISA disassembly, terminal logs, and memory bandwidth figures.

### 3. Hardware Authenticity & Micro-Architectural Representation

The UI directly maps to physical NVIDIA Hopper GH100 micro-architectural invariants:

1. **132 Streaming Multiprocessors (SMs)**:
   - Visualized as a 3D-styled physical silicon die grid (8 GPCs, TSMC 4N).
   - Real-time interactive inspection: selecting an SM highlights its interconnect.
   - Dynamic fault trap visualization: SM 14 flashes crimson during memory boundary violations (`SIGSEGV 139`).
2. **HBM3e 4-Stack Memory Highway**:
   - Four HBM3e stacks delivering up to `3.35 TB/s` bandwidth linked via an active laser bus crossbar to a `50MB` ultra-low-latency L2 cache.
3. **SIMT Warp 0 (32 Thread Lanes)**:
   - Full 32-lane matrix displaying SIMT lockstep execution.
   - Dual-mode inspection: *Unprotected CUDA* (threads $\ge 17$ trigger memory page fault) vs. *Aegis Hardened Triton* (threads $\ge 17$ evaluate `@p0 == 0`, suppressing memory transactions with 0 clock cycle branch penalty).
   - Live hardware register inspector displaying lane address, predicate register, and PTX instruction.
4. **4-Tier Memory Locality Waterfall**:
   - Traces dataflow across the complete hierarchy:
     1. *Tier 1: Global VRAM (HBM3e)* — 80 GB, 3.35 TB/s, ~250 cycles.
     2. *Tier 2: L2 Crossbar Cache* — 50 MB, 12.0 TB/s, ~35 cycles.
     3. *Tier 3: SM Shared Memory / SRAM (TMA)* — 228 KB/SM, 33.0 TB/s, ~18 cycles.
     4. *Tier 4: Tensor Core ALUs & Register File* — 64K registers, 989 TFLOPS peak, 1 cycle.
5. **Nsight Compute 100KHz Telemetry HUD**:
   - Real-time HUD showing 100% SM occupancy, 418.5 TFLOPS sustained Tensor throughput, zero branch divergence, and zero register spillover.

### 4. Interactive Proving Ground & Workflow Decomposition

The user controls an interactive loop with immediate hardware feedback:
- **Hardware Target Switcher**: Toggle between `Hopper H100 SXM5` (80GB, SM_90a), `Ada Lovelace L40S` (48GB, SM_89), and `Blackwell B200` (192GB, SM_100).
- **Workload Fixtures**: Select between `Fused SwiGLU` (LLaMA-3 / Mistral), `Vector RMSNorm` (Qwen-2.5 / DeepSeek), and `Online Softmax` (FlashAttention-v3).
- **Dynamic Sequence Length Scrubber**: Interactive slider from 128 to 4096 tokens. Real-time indicator warns when `seq_len % 32 != 0`, illustrating the exact mathematical edge case where unmasked kernels fault.
- **Autonomous Proving Loop**: Live Server-Sent Events (SSE) telemetry driving the 5-stage proving pipeline:
  `01 Tavily Recon` $\rightarrow$ `02 Red Fuzzer` $\rightarrow$ `03 Sandbox Crash` $\rightarrow$ `04 Nemotron Blue` $\rightarrow$ `05 Dual Invariant Verified`.
