# Aegis-Kernel UI-UX Architecture & Design System

## Executive Summary & Design Thesis

Aegis-Kernel bridges two competing visualization paradigms in high-performance computing: the dense diagnostic telemetry of NVIDIA Nsight / nvprof and the high-contrast executive visual clarity required for competitive pitch evaluation. Rather than choosing between spatial sparseness and technical depth, Aegis-Kernel introduces the **4-Stage Spatial Telemetry Workbench** with a unified **Top-Level Micro-Telemetry Status Hub** and zero layout collision.

```
+---------------------------------------------------------------------------------------------------------+
| [AEGIS-KERNEL]  Target: Hopper H100 SXM5 | Fixture: SwiGLU | SeqLen: [---o---] 1023 | [LAUNCH PROVING GROUND]|
+---------------------------------------------------------------------------------------------------------+
| [01 Red vs Blue Arena]   [02 132-SM & Warp Matrix]   [03 AST Diff & PTX]   [04 Nsight & Memory Waterfall]|
+---------------------------------------------------------------------------------------------------------+
| STAGE VIEWPORT (Dynamic Subsystem with Independent View States and Synchronized Audio-Visual Feedback)  |
|                                                                                                         |
|  - Zero Vertical Stacking Congestion (<940px Viewport Budget)                                          |
|  - Real-Time 100KHz Simulated Telemetry & SSE Event Binding                                             |
|  - Strict Hopper GH100 Hardware Mapping (132 SMs, 32-Lane SIMT Warps, @p0 Predication)                 |
+---------------------------------------------------------------------------------------------------------+
```

## Assumptions

1. **Host Environment**: The frontend runs on React 18+ bundled with Vite, styled with Tailwind CSS utility classes and dedicated CSS design tokens in `frontend/src/index.css`.
2. **Backend Communication**: Real-time proving execution is driven by Server-Sent Events (`EventSource`) at `http://localhost:8000/api/v1/execute/:fixture`, falling back to deterministic local state if disconnected.
3. **Hardware Modeling**: Target hardware default is NVIDIA Hopper GH100 SXM5 (132 Streaming Multiprocessors, 4 processing blocks per SM, 32 thread lanes per warp, 4-tier memory hierarchy: 80GB HBM3e @ 3.35 TB/s -> 50MB L2 Cache -> 228KB Shared Memory/L1 -> Tensor Core Register File).

---

## Dialectical Synthesis: Resolving Density vs. Congestion

* **Thesis (Information Density)**: HPC architects and GPU kernel engineers demand deep, continuous hardware metrics (SM occupancy, warp divergence, PTX disassembly, memory bandwidth saturation) rendered simultaneously.
* **Antithesis (Spatial Clarity)**: Executive presentation and cognitive clarity require uncluttered visual hierarchies, generous negative space (padding $\ge$ 16px, maximum 2-3 focused instruments per viewport), and elimination of multi-layer vertical scrolling.
* **Synthesis (Spatial Workbench with Decoupled Depth)**: A single persistent Executive Command Bar maintains real-time parameter control (hardware target selector, workload preset, dynamic sequence length scrubber, single-click proving launch). The workspace partitions into four dedicated stages:
  1. **Stage 01: Red vs Blue Collider & Verification Delta**: Fuzzer vs Healer duel, speedup multiplier, and invariant validation feed.
  2. **Stage 02: 132-SM Die Topology & 32-Warp Matrix**: Silicon floorplan with interactive SM inspection and 32-lane SIMT predication visualization.
  3. **Stage 03: AST Diff & PTX Disassembly**: Side-by-side syntax-highlighted code diff and PTX assembly inspection with `@p0` predication flags.
  4. **Stage 04: Nsight Profiler & Silicon Memory Waterfall**: Roofline analysis, hardware counters, and 4-tier physical memory dataflow.

## Component Architecture & State Orchestration

### 1. `App.jsx` (Workbench Root Controller)
Coordinates active stage navigation, SSE event lifecycle, audio synthesis cues, and global modal overlays.

```jsx
import React, { useState } from 'react';
import ExecutiveCommandBar from './components/ExecutiveCommandBar';
import RedBlueArena from './components/RedBlueArena';
import HopperDieTopology from './components/HopperDieTopology';
import WarpVisualizer from './components/WarpVisualizer';
import CodeDiffInspector from './components/CodeDiffInspector';
import TerminalWindow from './components/TerminalWindow';
import NsightTelemetryHud from './components/NsightTelemetryHud';
import SiliconMemoryWaterfall from './components/SiliconMemoryWaterfall';
import MicDropDelta from './components/MicDropDelta';
import VerificationImpact from './components/VerificationImpact';
import Footer from './components/Footer';
import AttestationModal from './components/AttestationModal';
import { sound } from './utils/audio';

export default function App() {
  const [selectedHardware, setSelectedHardware] = useState('NVIDIA Hopper H100 SXM5');
  const [selectedFixture, setSelectedFixture] = useState('swiglu');
  const [selectedSm, setSelectedSm] = useState(14);
  const [seqLen, setSeqLen] = useState(1023);
  const [isRunning, setIsRunning] = useState(false);
  const [currentStage, setCurrentStage] = useState('IDLE');
  const [progress, setProgress] = useState(0);

  const [logs, setLogs] = useState([]);
  const [tavilyData, setTavilyData] = useState(null);
  const [redData, setRedData] = useState(null);
  const [blueData, setBlueData] = useState(null);
  const [metrics, setMetrics] = useState(null);
  const [attestation, setAttestation] = useState('0x7f56b9fe02089399');
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [activeWorkbenchTab, setActiveWorkbenchTab] = useState('collider');

  const addLog = (text, type = 'info') => {
    const timestamp = new Date().toLocaleTimeString();
    setLogs(prev => [...prev, { text: `[${timestamp}] ${text}`, type }]);
  };

  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);
    setTavilyData(null);
    setRedData(null);
    setBlueData(null);
    setMetrics(null);

    addLog(`[INIT] Engaging Aegis-Kernel Autonomous Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'TAVILY_RECON') {
          setCurrentStage('TAVILY');
          addLog(data.message, 'info');
        } else if (data.stage === 'TAVILY_RECON_COMPLETE') {
          setTavilyData(data.tavily_intel);
          addLog(`[TAVILY ORACLE] Verified 128-bit vector alignment & PTX ISA specs for Hopper SM_90a.`, 'success');
        } else if (data.stage === 'RED_ATTACK_SYNTHESIS') {
          setCurrentStage('RED_ATTACK');
          addLog(data.message, 'info');
        } else if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          setRedData(data.red_attack);
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
          addLog(data.red_attack.stack_trace, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(data.message, 'info');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setBlueData(data.blue_patch);
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'DUAL_VERIFY') {
          setCurrentStage('VERIFYING');
          addLog(data.message, 'info');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(data.message, 'success');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={(val) => {
          setSeqLen(val);
          addLog(`[SLIDER] Dynamic sequence length set to ${val} tokens`, 'info');
        }}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <div className="aegis-workbench-container">
        <div className="workbench-stage-nav-bar font-mono">
          <div className="stage-nav-tabs">
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'collider' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('collider'); }}
            >
              <span className="nav-tag-num">01</span>
              <span>Red vs Blue Collider & Delta</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'silicon' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('silicon'); }}
            >
              <span className="nav-tag-num">02</span>
              <span>132-SM Die & 32-Warp Matrix</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'code' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('code'); }}
            >
              <span className="nav-tag-num">03</span>
              <span>AST Diff & PTX Disassembly</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'telemetry' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('telemetry'); }}
            >
              <span className="nav-tag-num">04</span>
              <span>Nsight Profiler & Memory Waterfall</span>
            </button>
          </div>

          <div className="stage-nav-telemetry">
            <span className="nav-telemetry-badge">
              <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
              {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
            </span>
          </div>
        </div>

        <div className="workbench-spacious-view">
          {activeWorkbenchTab === 'collider' && (
            <div className="tab-view-container tab-view-fade">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
                redData={redData}
                blueData={blueData}
              />
              <div className="spacious-two-col">
                <MicDropDelta metrics={metrics} selectedFixture={selectedFixture} />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
              <TerminalWindow logs={logs} onClear={() => setLogs([])} />
            </div>
          )}

          {activeWorkbenchTab === 'silicon' && (
            <div className="tab-view-container tab-view-fade">
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                />
              </div>
              <NsightTelemetryHud metrics={metrics} selectedHardware={selectedHardware} />
            </div>
          )}

          {activeWorkbenchTab === 'code' && (
            <div className="tab-view-container tab-view-fade">
              <CodeDiffInspector selectedFixture={selectedFixture} blueData={blueData} />
              <TerminalWindow logs={logs} onClear={() => setLogs([])} />
            </div>
          )}

          {activeWorkbenchTab === 'telemetry' && (
            <div className="tab-view-container tab-view-fade">
              <NsightTelemetryHud metrics={metrics} selectedHardware={selectedHardware} />
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall metrics={metrics} selectedHardware={selectedHardware} />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
            </div>
          )}
        </div>
      </div>

      <Footer />
      <AttestationModal 
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        fixtureId={selectedFixture}
        hardwareTarget={selectedHardware}
        attestationHash={attestation}
      />
    </div>
  );
}
```

## Hardware Authenticity Specifications

### 1. Hopper GH100 Full Die Representation (`HopperDieTopology.jsx`)
* **132 Streaming Multiprocessors**: Rendered as a cohesive silicon die matrix representing 8 Graphics Processing Clusters (GPCs).
* **Fault Injection State**: When Nemotron Red attacks, SM 14 is highlighted with high-intensity plasma coral pulse (`#FF0055`), indicating an active out-of-bounds memory dereference fault.
* **Healing State**: When Nemotron Blue synthesizes the `@p0` Triton guard, SM 14 transitions through amber analysis to stabilized laser emerald (`#00FF88`), synchronizing occupancy across all remaining 131 SMs.

### 2. 32-Thread SIMT Warp Execution (`WarpVisualizer.jsx`)
* **Lanes 0 to 31**: Individual thread lane inspection for Warp 0.
* **Hardware Predication**: Under Red attack with unmasked sequence length $N=1023$, Thread 31 operates out-of-bounds (OOB violation).
* **Hardened State**: Nemotron Blue's Triton compiler generates PTX `@p0 ld.global.v4` predication. Lane 31 dynamically disables execution via predicate register `p0 = 0`, neutralizing memory corruption without divergence penalty.

### 3. Silicon Memory Waterfall (`SiliconMemoryWaterfall.jsx`)
Visualizes physical bandwidth and latency across the 4 physical tiers:
* **HBM3e High-Bandwidth Memory**: 80 GB capacity, 3.35 TB/s peak bandwidth, ~250ns latency.
* **L2 Cache**: 50 MB shared SRAM pool, 12 TB/s bandwidth, ~40ns latency.
* **Shared Memory / L1 Data Cache**: 228 KB per SM, 33 TB/s aggregate bandwidth, ~15ns latency.
* **Hopper 4th-Gen Tensor Cores**: 418.5 TFLOPS FP16/BF16 sustained compute pipeline.
