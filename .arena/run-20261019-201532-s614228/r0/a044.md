# Aegis-Kernel UI-UX Architecture & Design System Specification
**Autonomous GPU Invariant & Kernel Proving Workbench**  
*Nebius AI Cloud × NVIDIA Global Hackathon 2026*

---

## 1. Assumptions & Design Scope

1. **Target Display & Viewport**: Designed primarily for desktop high-resolution engineering displays (1920×1080 FHD up to 4K Ultrawide 3840×1600), with responsive degradation down to 1280px.
2. **Target Hardware Fidelity**: Specifically focuses on NVIDIA Hopper GH100 (SM_90a, 132 SMs, 3.35 TB/s HBM3e) and Blackwell B200 (SM_100, NVLink 5, 8.0 TB/s), visualizing actual microarchitectural constructs: 32-thread SIMT warp execution lanes, `@p0` hardware predication masks, TMA asynchronous copies, and 4-tier memory waterfalls.
3. **Execution Delivery**: Non-destructive design specification. Delivers the architectural synthesis, visual design tokens, layout hierarchy, and concrete component-level code implementations ready for drop-in inclusion.

---

## 2. Dialectical Analysis: Finding the Optimal UI Architecture

### Thesis (Thesis A: Dense Single-Pane Operations Dashboard)
- **Strengths**: Maximum data density, zero context switching, all 10 microarchitectural instruments (132 SMs, 32 warp lanes, AST diff, PTX disassembly, memory waterfall, Nsight metrics) visible simultaneously.
- **Flaws**: Extreme visual congestion, ocular fatigue, 600px scrolling bottlenecks, cards competing for attention, failure of the "breathing room" requirement.

### Antithesis (Thesis B: Segmented Multi-Step Modal Wizard)
- **Strengths**: Zero congestion, pristine breathing room, isolated focus per stage.
- **Flaws**: Fractured situational awareness, loss of HPC supercomputer prestige, judges cannot observe the dynamic causal ripple effect (e.g., how moving the ragged sequence length slider instantly lights up out-of-bounds predicate lanes on SM 14 and updates the memory waterfall bandwidth in real-time).

### Synthesis: Hierarchical Spatial Cockpit with Synchronous Cross-Probe Bus
The optimal architecture is a **Hierarchical 4-Stage Spatial Stage Navigator coupled with a Persistent Executive Command Bar and Live Unified Cross-Probe Bus**:
1. **Persistent Executive Command Bar**: Keeps global hardware context (H100/B200), dynamic sequence scrubber ($N=1023$), active proving pipeline stage, and primary action controls pinned at the top.
2. **Dedicated Spatial Stages**: Eliminates vertical stacking and cramped card grids by routing deep analytical views into 4 uncluttered functional stages:
   - **Stage 01 (Red vs Blue Collider & Delta)**: Macro duel between Nemotron 3 Ultra fuzzer and Nemotron Blue Triton healer, featuring the 2.35x speedup delta.
   - **Stage 02 (132-SM Silicon Die & 32-Warp Matrix)**: Microarchitectural hardware mapping from full-chip SM die down to individual warp thread lanes and `@p0` predicate masks.
   - **Stage 03 (AST Diff & PTX Disassembly)**: Side-by-side formal syntax transformation showing unmasked C++ vs hardened Triton Python and low-level PTX instructions.
   - **Stage 04 (Nsight Profiler & Memory Waterfall)**: Quantitative telemetry verifying 418.5 TFLOPS compute throughput and 2.84 TB/s HBM3e to Tensor Core dataflow.
3. **Reactive Cross-Probe Interconnect**: State changes in any control (e.g. sequence length or selected SM) immediately propagate across the system telemetry bus without congesting the active canvas.

1. **Hopper GH100 Full-Die Silicon Matrix (132 SMs)**:
   - Interactive SVG/Canvas wafer layout organized into 8 Graphics Processing Clusters (GPCs).
   - Real-time heat mapping: SM 14 highlights in pulsing crimson during fuzzer execution, shifting to synchronized emerald upon blue kernel synthesis.
   - Interactive SM click inspection to isolate thread clusters.
2. **SIMT 32-Thread Warp Matrix**:
   - Explicit lane breakdown of Threads 0 through 31.
   - Dynamic ragged tail boundary visualization: with $N=1023 \pmod{32} = 31$, Thread Lane 31 demonstrates the exact boundary condition where unpredicated loads trigger memory boundary faults.
   - Live toggling between unmasked memory read (`SIGSEGV`) and `@p0 ld.global.nc` predicate-protected execution.
3. **4-Tier Silicon Memory Waterfall**:
   - Physical hierarchy dataflow: HBM3e (3.35 TB/s) $\rightarrow$ L2 Cache (50 MB @ 5.1 TB/s) $\rightarrow$ Shared Memory / TMA Asynchronous Buffer (228 KB per SM) $\rightarrow$ Tensor Cores (4th Gen Hopper).
   - Animated SVG flow particles displaying bandwidth utilization and zero-copy latency reduction.

## 6. Implementation Architecture

### A. Stage Navigator & Main Layout (`frontend/src/App.jsx`)
```jsx
import React, { useState } from 'react';
import ExecutiveCommandBar from './components/ExecutiveCommandBar';
import RedBlueArena from './components/RedBlueArena';
import HopperDieTopology from './components/HopperDieTopology';
import WarpVisualizer from './components/WarpVisualizer';
import CodeDiffInspector from './components/CodeDiffInspector';
import TerminalWindow from './components/TerminalWindow';
import NsightTelemetryHud from './components/NsightTelemetryHud';
import SiliconMemoryWaterfall from './components/SiliconMemoryWaterfall';
import MicDropDelta from './components/MicDropDelta';
import VerificationImpact from './components/VerificationImpact';
import Footer from './components/Footer';
import AttestationModal from './components/AttestationModal';
import { sound } from './utils/audio';

export default function App() {
  const [selectedHardware, setSelectedHardware] = useState('NVIDIA Hopper H100 SXM5');
  const [selectedFixture, setSelectedFixture] = useState('swiglu');
  const [selectedSm, setSelectedSm] = useState(14);
  const [seqLen, setSeqLen] = useState(1023);
  const [isRunning, setIsRunning] = useState(false);
  const [currentStage, setCurrentStage] = useState('IDLE');
  const [progress, setProgress] = useState(0);

  const [logs, setLogs] = useState([]);
  const [tavilyData, setTavilyData] = useState(null);
  const [redData, setRedData] = useState(null);
  const [blueData, setBlueData] = useState(null);
  const [metrics, setMetrics] = useState(null);
  const [attestation, setAttestation] = useState('0x7f56b9fe02089399');
  const [isModalOpen, setIsModalOpen] = useState(false);
  const [activeWorkbenchTab, setActiveWorkbenchTab] = useState('collider');

  const addLog = (text, type = 'info') => {
    const timestamp = new Date().toLocaleTimeString();
    setLogs(prev => [...prev, { text: `[${timestamp}] ${text}`, type }]);
  };

  const handleClearLogs = () => {
    sound.playClick();
    setLogs([]);
  };

  const handleLaunchProvingGround = () => {
    sound.playLaunch();
    setIsRunning(true);
    setCurrentStage('INIT');
    setProgress(5);
    setLogs([]);
    setTavilyData(null);
    setRedData(null);
    setBlueData(null);
    setMetrics(null);

    addLog(`[INIT] Engaging Aegis-Kernel Autonomous Proving Collider for [${selectedFixture.toUpperCase()}] on [${selectedHardware}]`, 'info');

    const eventSource = new EventSource(
      `http://localhost:8000/api/v1/execute/${selectedFixture}?hardware_target=${encodeURIComponent(selectedHardware)}`
    );

    eventSource.onmessage = (event) => {
      try {
        const data = JSON.parse(event.data);
        setProgress(data.progress || 0);

        if (data.stage === 'TAVILY_RECON') {
          setCurrentStage('TAVILY');
          addLog(data.message, 'info');
        } else if (data.stage === 'TAVILY_RECON_COMPLETE') {
          setTavilyData(data.tavily_intel);
          addLog(`[TAVILY ORACLE] Verified 128-bit vector alignment & PTX ISA specs for Hopper SM_90a.`, 'success');
        } else if (data.stage === 'RED_ATTACK_SYNTHESIS') {
          setCurrentStage('RED_ATTACK');
          addLog(data.message, 'info');
        } else if (data.stage === 'SANDBOX_RED_EXECUTE') {
          setCurrentStage('SANDBOX_FAIL');
          sound.playAlert();
          setRedData(data.red_attack);
          addLog(`[CRIMSON EXPLOIT] SM 14 OOB Read tripped: Exit Code ${data.red_attack.exit_code}`, 'alert');
          addLog(data.red_attack.stack_trace, 'alert');
        } else if (data.stage === 'BLUE_SYNTHESIS') {
          setCurrentStage('BLUE_SYNTHESIS');
          addLog(data.message, 'info');
        } else if (data.stage === 'BLUE_SYNTHESIS_COMPLETE') {
          setBlueData(data.blue_patch);
          addLog(`[NEMOTRON BLUE] Hardened Triton Kernel Synthesized with @p0 Predication.`, 'success');
        } else if (data.stage === 'DUAL_VERIFY') {
          setCurrentStage('VERIFYING');
          addLog(data.message, 'info');
        } else if (data.stage === 'COMPLETE') {
          setCurrentStage('COMPLETE');
          sound.playSuccess();
          setMetrics(data.metrics);
          setAttestation(data.attestation_hash || '0x7f56b9fe02089399');
          addLog(data.message, 'success');
          addLog(`[FORMAL INVARIANT ATTESTATION]: ${data.attestation_hash}`, 'success');
          setIsRunning(false);
          eventSource.close();
        }
      } catch (e) {
        console.error('SSE Parse Error:', e);
      }
    };

    eventSource.onerror = () => {
      setIsRunning(false);
      eventSource.close();
    };
  };

  return (
    <div className="aegis-app-wrapper">
      {/* Executive Command Cockpit */}
      <ExecutiveCommandBar 
        selectedHardware={selectedHardware}
        onSelectHardware={setSelectedHardware}
        selectedFixture={selectedFixture}
        onSelectFixture={setSelectedFixture}
        isRunning={isRunning}
        currentStage={currentStage}
        progress={progress}
        onRun={handleLaunchProvingGround}
        seqLen={seqLen}
        onSeqLenChange={(val) => {
          setSeqLen(val);
          addLog(`[SLIDER] Dynamic sequence length set to ${val} tokens`, 'info');
        }}
        onOpenPitch={() => setIsModalOpen(true)}
        onOpenPrModal={() => setIsModalOpen(true)}
      />

      <div className="aegis-workbench-container">
        {/* Spatial Workbench Stage Navigation Bar */}
        <div className="workbench-stage-nav-bar font-mono">
          <div className="stage-nav-tabs">
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'collider' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('collider'); }}
            >
              <span className="nav-tag-num">01</span>
              <span>Red vs Blue Collider & Delta</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'silicon' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('silicon'); }}
            >
              <span className="nav-tag-num">02</span>
              <span>132-SM Die & 32-Warp Matrix</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'code' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('code'); }}
            >
              <span className="nav-tag-num">03</span>
              <span>AST Diff & PTX Disassembly</span>
            </button>
            <button 
              className={`stage-nav-btn ${activeWorkbenchTab === 'telemetry' ? 'active' : ''}`}
              onClick={() => { sound.playClick(); setActiveWorkbenchTab('telemetry'); }}
            >
              <span className="nav-tag-num">04</span>
              <span>Nsight Profiler & Memory Waterfall</span>
            </button>
          </div>

          <div className="stage-nav-telemetry">
            <span className="nav-telemetry-badge">
              <span className="pulse-indicator bg-nvidia inline-block mr-1"></span>
              {currentStage === 'IDLE' ? 'PROVING INSTRUMENT ARMED' : `STAGE: ${currentStage}`}
            </span>
          </div>
        </div>

        {/* Dynamic Spatial Workbench Content View */}
        <div className="workbench-spacious-view">
          {activeWorkbenchTab === 'collider' && (
            <div className="tab-view-container tab-view-fade">
              <RedBlueArena 
                currentStage={currentStage}
                isRunning={isRunning}
                selectedFixture={selectedFixture}
                metrics={metrics}
                redData={redData}
                blueData={blueData}
              />
              <div className="spacious-two-col">
                <MicDropDelta 
                  metrics={metrics} 
                  selectedFixture={selectedFixture} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {activeWorkbenchTab === 'silicon' && (
            <div className="tab-view-container tab-view-fade">
              <div className="spacious-two-col-grid">
                <HopperDieTopology 
                  currentStage={currentStage} 
                  isRunning={isRunning} 
                  onSelectSm={setSelectedSm}
                  selectedSm={selectedSm}
                />
                <WarpVisualizer 
                  selectedFixture={selectedFixture} 
                  isRunning={isRunning} 
                  currentStage={currentStage} 
                />
              </div>
              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
            </div>
          )}

          {activeWorkbenchTab === 'code' && (
            <div className="tab-view-container tab-view-fade">
              <CodeDiffInspector 
                selectedFixture={selectedFixture} 
                blueData={blueData} 
              />
              <TerminalWindow 
                logs={logs} 
                onClear={handleClearLogs} 
              />
            </div>
          )}

          {activeWorkbenchTab === 'telemetry' && (
            <div className="tab-view-container tab-view-fade">
              <NsightTelemetryHud 
                metrics={metrics} 
                selectedHardware={selectedHardware} 
              />
              <div className="spacious-two-col">
                <SiliconMemoryWaterfall 
                  metrics={metrics} 
                  selectedHardware={selectedHardware} 
                />
                <VerificationImpact 
                  metrics={metrics} 
                  selectedFixture={selectedFixture}
                  onOpenPrModal={() => setIsModalOpen(true)}
                  onOpenJudgesOverview={() => setIsModalOpen(true)}
                />
              </div>
            </div>
          )}
        </div>
      </div>

      <Footer />

      <AttestationModal 
        isOpen={isModalOpen}
        onClose={() => setIsModalOpen(false)}
        fixtureId={selectedFixture}
        hardwareTarget={selectedHardware}
        attestationHash={attestation}
      />
    </div>
  );
}
```
