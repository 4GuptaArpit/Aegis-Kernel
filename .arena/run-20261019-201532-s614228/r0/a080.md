## 1. Executive Summary & Design Tenets

Aegis-Kernel bridges the gap between deep compiler telemetry and executive verification for autonomous GPU kernel optimization. By pairing **Nemotron Red** (an adversarial fuzzing agent identifying out-of-bounds memory hazards and warp divergences) with **Nemotron Blue** (a formal Triton repair agent emitting `@p0` predication and fused SRAM pipelines), the system provides mathematically sound kernel synthesis on **NVIDIA Hopper GH100** and **Blackwell B200** hardware.

### Core Architectural Tenets
1. **Zero-Congestion Spatial Topology**: Eliminates deep vertical scrolling and crowded widget mosaics through a 4-stage spatial workbench navigation model.
2. **First-Principles Hardware Authenticity**: Displays true architectural primitives—132 Streaming Multiprocessors (SMs) across 8 Graphics Processing Clusters (GPCs), 32-thread lockstep SIMT execution lanes, 4-tier memory waterfalls, and 100 kHz Nsight telemetry.
3. **High-Contrast Cyber-Physical Aesthetic**: Employs deep obsidian dark space (`#03060D`) punctuated by laser emerald (`#00FF88`), plasma coral (`#FF0055`), and hyper-cyan (`#00F0FF`) with subtle CSS glow physics and ambient reactor gradients.
4. **Instant Actionability & Interactive Scrubbing**: Enables zero-latency hardware switching, dynamic sequence length scrubbing (triggering tail-thread SIMT masking in real time), and single-click proving ground execution.

## 2. Assumptions

1. **Host Environment**: The frontend runs on a modern Chromium-based browser supporting CSS Grid Level 2, CSS backdrop-filter, flexbox, and HTML5 Web Audio API.
2. **Backend Communication**: Real-time proving runs communicate via standard Server-Sent Events (SSE) streaming from `/api/v1/execute/{fixture_id}`.
3. **Target Silicon**: Primary simulation focuses on NVIDIA Hopper GH100 SXM5 (132 SMs, 80 GB HBM3e, SM_90a ISA) with extensible runtime profiles for NVIDIA Blackwell B200 (SM_100) and Ada Lovelace L40S (SM_89).

### Second-Order State Feedback Loops
- **Scrubber to Warp Matrix**: Modifying `seqLen` directly recalculates `seqLen % 32`. If ragged (`remainder != 0`), Warp 0 marks tail lanes with `@p0 = 0` (suppressed) and updates memory footprint across the HBM3e waterfall.
- **SSE Stream to Multi-Component Reactor**: When the Red Fuzzer triggers an out-of-bounds trap (`SANDBOX_FAIL`), SM 14 in `HopperDieTopology` pulses crimson coral, Warp 0 Lane 17 enters an MMU fault state, and `TerminalWindow` displays the stack trace without layout jank.
- **Nemotron Blue Convergence**: Upon synthesis completion, the AST diff renders side-by-side color-coded lines, the delta speedometer springs to `2.35x`, and the memory waterfall drops global VRAM round-trips by 42%.

## 5. Screen-by-Screen Component Specifications

### 5.1 Executive Command Cockpit
- **Hardware Target Switcher**: Interactive selector supporting Hopper H100 (80GB, SM_90a), Blackwell B200 (192GB, SM_100), and Ada L40S (48GB, SM_89). Displays active memory bandwidth and core clocks dynamically.
- **Workload Selector**: Instant presets for Fused SwiGLU (LLaMA-3), RMSNorm (Qwen-2.5), and Online FlashAttention-v3.
- **Dynamic Sequence Length Scrubber**: Range slider (128 to 4096 tokens). Dynamically highlights ragged boundary status (`seqLen % 32 != 0`) and warning tags for unmasked SIMT tail hazards.
- **Global Proving Ground Trigger**: High-voltage emerald CTA with dynamic progress bar and live stage badge.

### 5.2 Stage 01: Red vs Blue Collider & Mic-Drop Delta
- **Adversarial Dual Arena**: Left column hosts Nemotron Red Fuzzer (generates unaligned memory strides, rogue warp offsets, and buffer overflow vectors); right column hosts Nemotron Blue (synthesizes `@p0` predication masks and SRAM tiling).
- **Mic-Drop Delta Scorecard**: Displays verified performance metrics:
  - **Latency**: 18.4 μs (Unoptimized Baseline) down to 7.8 μs (Healed Triton).
  - **Speedup Ratio**: Real-time counter animating to `2.35x`.
  - **HBM3e Traffic**: Reduced from 1.42 GB to 0.82 GB (-42.2%).
  - **Warp Execution Efficiency**: 99.4% with zero warp divergence cycles.
- **Streaming Terminal Feed**: ANSI-colored log console with timestamped entries, collapsible log clearing, and system status indicators.

### 5.3 Stage 02: 132-SM Die & 32-Warp Execution Matrix
- **Hopper GH100 Silicon Topology**:
  - Full die layout modeling 8 Graphics Processing Clusters (GPCs).
  - 132 individual Streaming Multiprocessor tiles rendered in responsive grid.
  - Interactive SM selection: Clicking any SM routes telemetry directly into the inspector.
  - Live fault highlighting: SM 14 pulses with crimson warning glow during adversary injection and transitions to verified emerald upon Triton repair.
- **SIMT Warp 0 Execution Matrix**:
  - 32 discrete thread execution lanes representing hardware SIMT lockstep dispatch.
  - Real-time lane status breakdown: Active lanes (0–16), ragged boundary lane (17), and masked tail lanes (18–31).
  - Hardware Predicate Inspector: Displays PTX instruction `ld.global.nc.v2.f16` predicated under `@p0` and hardware zero register allocation (`0.0000`).

### 5.4 Stage 03: AST Diff & PTX Disassembly
- **Dual-Pane Code Inspector**:
  - Left pane: Vulnerable CUDA C++ code highlighting missing boundary guards and unsafe raw pointer arithmetic.
  - Right pane: Hardened Triton Python code featuring explicit `tl.load(..., mask=mask, other=0.0)`.
- **PTX ISA Assembly Viewer**:
  - Highlights Hopper SM_90a assembly showing hardware predicated instructions (`@p0 ld.global`) and TMA (Tensor Memory Accelerator) descriptors.

### 5.5 Stage 04: Nsight Profiler & 4-Tier Memory Waterfall
- **Nsight Telemetry HUD**:
  - Key Performance Indicators: 418.5 TFLOPS Tensor throughput (92.4% roofline), 2.84 TB/s HBM3e bandwidth (84.8% peak), and 94.2% L2 cache hit rate.
- **4-Tier Silicon Memory Waterfall**:
  1. *Tier 1: Global VRAM (HBM3e)* — 80 GB, 3.35 TB/s, ~250 clock cycles.
  2. *Tier 2: L2 Crossbar Cache* — 50 MB, 12.0 TB/s, ~35 clock cycles.
  3. *Tier 3: SM Shared Memory / SRAM (TMA)* — 228 KB per SM, 33.0 TB/s, ~18 clock cycles.
  4. *Tier 4: Tensor Core ALU & Register File* — 64K registers, 989 TFLOPS peak, 1 cycle.
  - Contrasts naive memory thrashing against fused SRAM execution side-by-side.
