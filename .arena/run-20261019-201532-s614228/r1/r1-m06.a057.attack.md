ATTACK 3 [MAJOR] WarpVisualizer hardcodes lane 31 OOB fault and ignores dynamic sequence length edge cases
Where: `frontend/src/components/WarpVisualizer.jsx` lines 607-615:
```jsx
{lanes.map((lane) => {
  const isOobLane = lane === 31;
  let laneState = 'nominal';
  if (isOobLane) {
    if (isRedBreach) laneState = 'breach';
    else if (isBlueHardened) laneState = 'masked';
  }
```
Problem: Task Requirement 4 demands authentic SIMT 32-thread warp representation. In SIMT execution, the ragged boundary is dynamic: for an arbitrary sequence length `N`, the tail lanes beyond `N % 32` (or vector chunk alignment) are out-of-bounds. For example, if `seqLen = 1041` (`1041 % 32 = 17`), lanes 17 through 31 are out-of-bounds. a040 hardcodes `const isOobLane = lane === 31;` unconditionally in a static loop without taking `seqLen` as a prop at all, making the component physically incorrect for every ragged sequence length except specifically $32k - 1$.
