ATTACK 6 [MINOR] Factual hardware error: claims NVIDIA Hopper GH100 SXM5 uses HBM3e instead of HBM3
Where: `r0/a015.md#L17`, `r0/a015.md#L56`, and `r0/a015.md#L162`
Problem: Requirement 4 requires authentic representation of NVIDIA Hopper GH100 architecture. Section 1 (`r0/a015.md#L17`) and Section 5.4 specify the target hardware as:
`NVIDIA Hopper GH100 SXM5 (80GB HBM3e, 132 SMs, SM_90a)`.
This is technically inaccurate: the NVIDIA Hopper GH100 SXM5 GPU features 80GB of HBM3 memory across 5 active stacks with a peak bandwidth of $3.35\text{ TB/s}$. HBM3e memory was not introduced until the NVIDIA H200 (141GB HBM3e at $4.8\text{ TB/s}$) and the Blackwell B200 (192GB HBM3e at $8.0\text{ TB/s}$). Mislabelling the GH100 memory subsystem as HBM3e misrepresents NVIDIA's published hardware specifications on an evaluation specifically judging hardware authenticity.
