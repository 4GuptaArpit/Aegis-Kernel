# Draft: Aegis-Kernel UI/UX Architecture & System

## User Archetypes
1. Systems & Kernel Engineer (Wants PTX, Predicates, Warp divergence)
2. Nebius / NVIDIA Judge (Wants the GA-GA visual wow-factor, speedup delta, clean workflow)
3. Research Scientist (Wants mathematical invariants, SDC detection, convergence)

## Core Pain Points of Baseline
- Rigid 4-tab model hides state: when you run, you can't see the die and the code diff at the same time unless you switch tabs.
- When running, user loses situational awareness.
- What if there is an Executive Overview mode + Deep Dive Stage mode with spatial split & breathing room?
- What if the command bar has tactile feedback, scrubber with instant SIMT warp alignment warnings, and live memory latency indicators?
